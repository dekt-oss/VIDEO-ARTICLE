# 술째리고 — 페이스북 로그인 연결 추가 안내 (2026-10-30)

목적: 인스타 **인기 음원**을 릴스에 붙이고(Audio API), 인기 음원 목록을 매일 받아 오기 위해서다.
Meta 는 이 기능을 "페이스북 로그인" 방식에만 연다 — 지금 쓰는 "인스타그램 로그인" 방식에서는 막혀 있다.

**지금 게시는 건드리지 않는다.** 기존 토큰(`SOOLJJERIGO_IG_TOKEN`)과 게시 경로는 그대로 두고,
새 토큰을 **옆에 하나 더** 둔다(`SOOLJJERIGO_FB_TOKEN`). 음원 붙이기가 시험에서 되는 것을 본 뒤에야
게시를 새 토큰으로 옮긴다. 엔진은 두 방식을 이미 다 안다(`engine/providers/instagram.py` 의 `facebook_login`).

## 운영자가 하실 일 (약 30분, 비밀번호 입력이 있어 대신할 수 없음)

### 1. 페이스북 페이지 만들기 (없으면)
- facebook.com/pages/create → 이름 "술째리고", 카테고리는 아무거나 가까운 것(예: 미디어/뉴스).
- 성공: 페이지가 생기고 내가 관리자로 보인다.

### 2. 인스타 계정을 그 페이지에 연결
- 페이스북 페이지 → 설정 → **연결된 계정**(Linked accounts) → Instagram → 연결 → sooljjerigo 로 로그인.
  (인스타 앱에서 하려면: 프로필 편집 → 페이지 → 연결)
- 성공: 페이지 설정의 Instagram 칸에 sooljjerigo 가 보인다.

### 3. Meta 개발자 앱에 페이스북 로그인 권한 추가
- developers.facebook.com/apps → 지금 쓰는 앱 → 사용 사례(Use cases) → Instagram 관련 사용 사례 → 사용자 지정(Customize).
- "**페이스북 로그인으로 API 설정**"(API setup with Facebook login) 쪽에서 아래 권한을 추가한다. 화면 이름은 조금 다를 수 있다.

| 권한 | 쓰임 |
|---|---|
| `instagram_basic` | 계정 읽기 (필수) |
| `instagram_content_publish` | 릴스 게시 + 음원 붙이기 (필수) |
| `instagram_manage_insights` | 성과 지표 — ★ 지난번에 이게 빠져 토큰을 버렸다 |
| `pages_show_list` | 연결된 페이지 찾기 |
| `pages_read_engagement` | 페이지 통해 인스타 계정 찾기 |
| `business_management` | 페이지가 비즈니스 계정 소속일 때 필요 |

- ⚠ **넣지 말 것**: 광고(`ads_*`), 메시지(`instagram_manage_messages`, `pages_messaging`) — 지난번 토큰이 이게 섞여 버려졌다.

### 4. 토큰 받기
- developers.facebook.com/tools/explorer (Graph API 탐색기)
- 오른쪽에서 앱 선택 → "사용자 토큰"(User Token) → 3번의 권한 6개 체크 → **Generate Access Token**.
- 페이스북 로그인 창이 뜨면: 술째리고 페이지와 sooljjerigo 인스타를 **선택해서** 허용.
- 이렇게 받은 토큰은 1시간짜리다 → 5번에서 늘린다.

### 5. 토큰을 60일짜리로 늘리기
- developers.facebook.com/tools/debug/accesstoken (액세스 토큰 디버거) → 4번 토큰 붙여넣기 → 디버그.
- 아래쪽 **Extend Access Token**(액세스 토큰 연장) → 새로 나온 긴 토큰을 복사.
- 확인: "범위(Scopes)"에 3번의 6개가 있고, 광고·메시지 권한은 없다. 만료가 약 60일 뒤로 나온다.

### 6. 토큰 저장 — ★ 채팅에 붙여넣지 마세요
- 터미널에서 (값을 물어보면 붙여넣고 엔터 — 화면에 안 보이는 게 정상):

```bash
gh secret set SOOLJJERIGO_FB_TOKEN
```

- 로컬 `.env` 파일 맨 아래에 한 줄 추가: `SOOLJJERIGO_FB_TOKEN=받은토큰`
- 끝나면 채팅에 "넣었어" 라고만 알려 주세요.

## 그 뒤에 제가 할 일 (비용 0원, 읽기만)
1. 새 토큰으로 페이지 연결과 인스타 ID(17841473765861006)가 보이는지 확인.
2. 인기 음원 목록(`GET /ig_audio`, 검색어 없이)이 실제로 오는지 확인 — 한국 계정에서 몇 곡이 오는지.
3. 결과를 보여 드리고, 음원을 붙인 **시험 게시**를 할지 따로 여쭙니다. 인스타 API 에는 비공개 게시가 없어 시험 게시도 **공개 게시**이고,
   API 가 삭제를 못 해서 앱에서 손으로 지워야 한다.

## 오해하기 쉬운 점 — 가져오는 것은 페이스북 글이 아니라 인스타 내용이다
"페이스북 로그인"은 **들어가는 문(인증 방식)** 이름일 뿐이다. 받아 오는 인기 음원·해시태그 게시물은
전부 인스타 릴스·게시물이고, 페이스북 글은 하나도 모으지 않는다. 페이지는 Meta 가 요구하는 연결 고리다.
인스타그램 로그인 방식으로는 **내 계정 것만** 읽을 수 있고, 남의 인스타 내용(인기 음원·해시태그·다른 계정)을
읽는 공식 통로는 모두 페이스북 로그인 쪽에만 있다.

## 알아 두실 것
- **만료**: 이 토큰도 60일이다(지금 토큰과 같음). 자동 갱신은 따로 만들어야 한다 — 만료 2주 전 알림부터 넣을 예정.
- **앱 심사**: 음원 기능은 문서상 권한 두 개(`instagram_basic`·`instagram_content_publish`)만 요구한다. 앱이 개발 모드여도
  앱 관리자 본인 계정에는 보통 작동한다(미검증 — 2번 확인에서 판정).
- **해시태그 인기 게시물(밈 수집)은 이번 전환으로 안 열린다.** Meta 문서가 "앱 심사 + Instagram Public Content Access
  승인"을 요구한다 — 비즈니스 인증·개인정보처리방침·시연 영상이 필요해 몇 주 걸린다. 이건 따로 결정한다.
  그동안 밈은 인기 음원 목록 + 유튜브 쇼츠 + 네이버 글 + 운영자 링크로 모은다.
- 미리보기 불가: 음원 붙인 릴스는 게시 전에 들어 볼 수 없다(Meta 문서). 그래서 시험 게시(공개)가 한 번 필요하다.
