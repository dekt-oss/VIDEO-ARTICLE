## 무엇을 만들었나

**결재 = 상한(DB 가 막는다)** — `supabase/migrations/0054_drinks_spend.sql`
- `drink_spend_approvals`: 결재 1건(단계·목적·상한·허용 종류·결재권자의 말 원문·주문서 해시·기한). 내용은 바꿀 수 없고 열림 → 닫힘만.
  상한은 1건당 $10 을 넘을 수 없다(실수로 0 을 더 붙이는 것 방지).
- `drink_spend_holds`: 유료 호출 1회 직전의 가잡기. `drinks_hold_spend` 가 결재 행을 잠그고
  (가잡힘 + 확정 + 이번 예상) ≤ 상한 일 때만 만든다. 호출이 끝나면 확정(실제 금액) 또는 해제(실패 — 청구 없음).
  - 같은 결재 안에서 같은 항목은 한 번만 산다(가잡는 중 `hold_in_progress`, 이미 산 것 `already_bought`).
  - 같은 항목의 유료 시도는 3번까지(`retry_limit`) — 넘으면 멈추고 보고한다.
  - 워커가 가잡기 뒤에 죽으면 그 금액은 가잡힌 채 남아 상한을 차지한다. 틀리면 **덜 쓰는 쪽**으로 틀린다.
  - 확정은 임대를 잃어도 받는다(돈은 이미 나갔으니 기록돼야 한다). 새 가잡기는 임대가 있어야 한다.
- `drink_generated_assets`: 산 그림·영상의 재사용 목록(모델·프롬프트·이어 그릴 그림·규격의 해시 → 파일).
  확정된 지출에만 붙는다. 같은 그림을 두 번 사지 않는다.
- `drinks_request_render(paid)`: 그 제작안 전용 열린 결재가 있고, 새로 들 예상이 남은 금액 안일 때만 큐에 넣는다.
  예상은 장면 역할로 센다(3D 도해 $0.134, 실사형 $0.039, 정리 카드 0). 이 제작안 버전으로 이미 산 장면은 0.
  대기 중에 결재가 닫히면 시작하지 않고 취소한다(`approval_closed`).
- `drinks_validate_plan`: 장면의 영어 그림·움직임 지시문(`visual_prompt`·`motion_prompt`)을 보존한다(전엔 버렸다).

**사기** — `engine/drinks_paid.py`
- 장면 → 주문 항목. 프롬프트는 엔진 실사형 그림 경로(`providers.image._build_image_prompt`)가 만든다 —
  2026-09-08 확정 화풍(무광 CG, `VISUAL_ROLE_STYLE`)과 글자 금지를 그대로 탄다. 주문서에 찍히는 문장 = 실제로 보내는 문장.

- `continuity: "ref:N"` 이면 N번 그림을 이어 그린다(같은 세계). 시험 스크립트와 워커가 같은 함수를 써서 같은 장면은 같은 해시다.

  키가 없으면 가잡기 **전에** 멈춘다. Veo 가 만들고 받기만 실패한 경우는 청구 유력으로 보고 확정한다(엔진 `VeoBilledRejection`).

- **대본 v2**(`docs/drinks-pilot/gi-sake-v1.json`, `script_rev`): 문어체("~에 따르면 ~할 수 있습니다") → 말하듯이("안 돼요. ~해 줘야 해요").
  질문 → 바로 답 → 이름 붙이기(지리적 표시) → 생긴 이유 → 넓어진 시점 → 좋은 점 → 행동 순서. 사실은 그대로(c1~c3 원문 대조).
  그림 지시문은 바꾸지 않았다 → 산 그림 3장을 그대로 다시 썼다(0원).
- **자막**: 엔진은 어절 **개수**(최대 3)로만 끊어서 "그 지역만의 / 특성이"처럼 꾸밈이 갈렸다.
  `engine/subtitles.phrase_groups` — 쉼표·문장 끝에서 끊고, 조사·어미로 끝나는 어절 뒤를 선호하고, 관형형(된·할·쓸)·관형사(그·모든)·
  '-의'·조사 없는 명사 뒤와 의존 명사(수·때·것) 앞뒤에서는 끊지 않는다. 너무 짧은 줄은 문장 경계를 넘지 않고 약한 끊김 쪽으로 합친다.
  `config.CAPTION_PHRASE_BREAKS` 로 켜며 **주류 렌더만** 켠다(논문·리포트 자막은 그대로 — 켜려면 운영자 확인 후).
