# 세부 작업지시서 — 세마글루타이드 (지시서 `e7793db0`)

실제로 렌더를 돌린 지시서 전문이다. 화면·움직임 지시는 영어라 **한글로 옮겨 적었다**.
오른쪽에 **옛 렌더가 실제로 만든 것**(잡 `c43d87a4` 실측)과 **새 시퀀스 렌더가 만들 것**을 붙였다.

논문: *Late-life semaglutide treatment slows ageing and extends lifespan* (UC Berkeley, Nature)

### 장면 S4 — 칼로리 제한과의 비교 (세계가 세포로 바뀜)

**컷 8** · **MECHANISM** · 추정 8초 · 새 에셋 ← ★ **문제의 컷**
- **나레이션**: "세마글루타이드는 칼로리 제한과 유사하게 노화 관련 기능 저하를 완화할 뿐만 아니라,
  탐색 행동, 공간 기억, 혈당 조절에서는 칼로리 제한보다 더 유리한 궤적을 보였습니다."
- **화면**: **화면 분할**로 두 평행 과정. **왼쪽**은 양식화된 노화 세포 위에 '칼로리 제한'
  기호(빈 접시 아이콘)가 떠 있고 미미한 개선을 보임. **오른쪽**은 같은 노화 세포에
  '세마글루타이드' 분자(초록색, 길쭉함)가 다가와 결합하며 더 뚜렷하게 건강하고 활동적인
  세포로 변형되기 시작. 동시에 신경 경로(공간 기억·탐색 행동)와 췌장 세포(혈당 조절)를
  나타내는 작고 빛나는 표현이 세마글루타이드 쪽에 나타나 더 선명해짐.
- **움직임**: 세마글루타이드 분자가 세포에 능동적으로 결합해 내부 변화의 연쇄를 촉발.
  오른쪽에서 신경·췌장 세포 표현이 눈에 띄게 밝아지고 활동이 증가하는 반면,
  칼로리 제한 쪽은 미미하고 덜 역동적인 개선만 보임.
- **자막 카드**: `칼로리 제한 유사 효과 + 탐색 행동, 공간 기억, 혈당 조절 우위` (0.5초부터 6초간)
- **기전 선언**: 초기 상태 = 노화 세포의 기능 저하 → 변형 = 세마글루타이드가 결합해 염증을 줄이고
  NAD+ 를 높이며 유전자 발현을 유도 → 최종 상태 = 활성화된 건강 세포와 향상된 신경·췌장 기능

- **움직임**: 카메라가 세포에서 꾸준히 물러나는 동안 초록 분자 셋이 각자의 경로로 나아가

### 장면 S5 — 작용 원리 3단

**컷 10** · MECHANISM · 추정 4초 · 재사용(상태 변화)
- **나레이션**: "세마글루타이드는 노화 관련 염증을 줄이고"
- **화면**: 양식화된 동물 세포 주위에 작고 붉은 가시 모양의 염증성 사이토카인 분자들이 많이 있음.
  초록색 길쭉한 세마글루타이드 분자가 나타나 사이토카인 쪽으로 이동하며 그것들이 눈에 띄게
  줄어들고 사라짐. 화면에 글자 없음.
- **움직임**: 세마글루타이드 분자가 장면을 가로지르며 붉은 사이토카인이 빠르게 감소하고 흐려짐.

**컷 11** · MECHANISM · 추정 3초 · 재사용(상태 변화)
- **나레이션**: "NAD+ 수준을 높이며"
- **화면**: 양식화된 동물 세포의 단면, 내부에 파랗게 빛나는 NAD+ 분자 몇 개. 초록 세마글루타이드
  분자가 세포로 들어가고, 이어 NAD+ 분자들이 급격히 늘어나며 더 밝게 빛남. 화면에 글자 없음.
- **움직임**: 분자가 세포 안으로 이동하고, 내부 NAD+ 가 수가 늘고 강도가 세지며 더 밝은 파란빛을 발함.

**컷 12** · MECHANISM · 추정 8초 · 재사용(상태 변화)
- **나레이션**: "노화 조절 유전자의 발현을 유도하는 등 다양한 메커니즘으로 노화를 늦추는 것으로 나타났습니다."
- **화면**: 세포핵의 정밀한 3D 렌더링. 단단히 감긴 DNA 이중나선과 비활성 유전자 발현 복합체.
  초록 세마글루타이드 분자가 핵으로 들어가 복합체에 결합하고, 복합체가 빛나며 DNA 나선이
  부분적으로 풀림 — 유전자 활성화를 상징. 화면에 글자 없음.
- **움직임**: 분자가 핵으로 진입해 유전자 발현 복합체와 상호작용하고, 복합체가 눈에 띄게
  활성화되며 DNA 가닥이 천천히 풀림.

### 장면 S6 — 한계

**컷 13** · REALITY · 추정 5초 · 새 에셋

- **움직임**: 카메라가 선명한 암컷 우리에서 배경의 흐릿한 수컷 우리로 천천히 패닝하며 범위 한계를 강조.
- **자막 카드**: `암컷 생쥐 대상 연구` (0.5초부터 3초간)

**컷 14** · REALITY · 추정 7초 · 재사용(상태 변화)
- **나레이션**: "인간에게도 동일한 효과가 나타날지는 장기적인 임상 연구가 더 필요합니다."
- **화면**: 새벽의 임상 연구 건물, 넓고 텅 빈 복도. 한쪽 벽을 따라 빈 의자들이 줄지어 있고
  높은 창으로 부드러운 자연광이 들어옴. 전경에 흰 가운을 입은 연구원 한 명이 카메라를 등지고
  서서 닫힌 폴더를 들고 긴 빈 복도를 내려다봄. 실사, 조용하고 사색적. 화면에 글자 없음.
- **움직임**: 카메라가 연구원을 지나 빈 복도를 따라 천천히 달리인, 왼쪽으로 빈 의자들이 흘러가고
  끝의 밝은 창에서 멈춤.
- **자막 카드**: `인간 적용: 추가 임상 연구 필요` (0.5초부터 4초간)

## 3. 무엇이 달라지나 — 세 가지

**① 컷 8의 4.66초 정지가 사라진다**
나레이션이 12.66초인데 클립이 8초라 4.66초를 얼어붙은 채 보냈다. 새 방식은 컷 8·9를
S4 장면 하나로 묶어 20초를 만들고, 컷 8은 그중 앞 13.1초 구간을, 컷 9는 이어지는 구간을 본다.
**화면은 계속 움직이고 컷 경계에서 끊기지 않는다.**

**② 같은 지시문을 두 번 만들던 낭비가 사라진다**
컷 3·4는 화면 지시가 글자 그대로 같고(사육장 두 개 나란히), 컷 5·6도 같다(연구원의 손).
옛 방식은 각각 따로 생성했다 — 돈도 두 번 들고, **같은 장면인데 생성기가 다르게 그려서**
컷이 바뀌는 순간 화면이 튄다. 새 방식은 한 영상의 다른 구간을 볼 뿐이라 튀지 않는다.

**③ 시작 그림이 14장 → 6장**
장면마다 1장만 만들고 그 안의 클립들은 앞 클립의 마지막 프레임에서 이어받는다
(표의 "이어받기"). 이미지 생성비가 줄고, **장면 안에서 인물·배경·조명이 유지된다.**

## 4. 아직 확인되지 않은 것

위 "새 방식"은 **계획 모듈이 계산한 값**이지 실제 렌더 결과가 아니다.
코드는 다 들어갔고(`768a987` + `1ef99b3`) 테스트 1,740개가 통과했지만,
**실제로 영상을 뽑아 정지가 사라졌는지는 아직 눈으로 보지 않았다.**

막고 있는 것: 로컬에 ffmpeg 미설치, GitHub Actions 한도 소진(10/1까지).
`winget install ffmpeg` 후 `python -m engine.render` 로 한 편 뽑으면 확인된다.
