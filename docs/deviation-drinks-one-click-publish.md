# [게시] 한 번 (2026-11-13)

운영자: "이미 게시 눌렀는데 게시시간 넣으라고 뜨는 건 뭐야?"

## 원인
발행은 [발행안 만들기] → [승인 요청](시각 필수) → [승인](지문) → [예약] 네 번이었다. [발행안 만들기]는 작성 중(draft)만 만든다.
게다가 예약 크론(`DRINKS_PUBLISH_CRON_ENABLED`)이 꺼져 있어, 예약해도 수동 실행 전에는 올라가지 않는다.

## 바꾼 것
- DB 0086 `drinks_publication_go`: 화면에 보인 버전의 발행안을 시각 채움(없으면 지금) → 승인 요청 → 승인 → 예약까지 한 트랜잭션.
  각 단계는 기존 함수를 그대로 부른다(캡션 형식·AI 표시·파일 유효성·발행 차단 검사 그대로). 지문은 같은 트랜잭션에서 만든 것이고
  운영자가 본 내용은 expected_version 이 보장한다.
- 화면: 발행안 칸 버튼이 [지금 게시]/[예약 게시] 하나. 결정 바도 작성·승인 대기·승인 상태에서 [게시] 하나.
- 지금 게시면 발행 워커를 바로 깨운다(크론이 꺼져 있어도 올라간다).

## 남은 것
- 예약 게시(2026-11-13 운영자 "시간 넣으면 예약되는 거"): 작성 중 발행안에도 시각 칸을 붙였고, 예약 크론을 켰다(`DRINKS_PUBLISH_CRON_ENABLED=1`). 크론은 KST 07:00~23:30 매 30분이라 정한 시각 뒤 첫 30분 눈금에 올라간다(최대 30분 늦음).
