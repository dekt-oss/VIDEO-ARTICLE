# deviation — 리포트 영상 '모션그래픽(motion)' 버전 추가 (2026-11-24)

## 무엇을 바꿨나
- 리포트 라인에 새 영상 버전 `motion` 을 더했다. 계획서: `docs/plans/2026-11-24-motion-graphics-engine.md`.
- 그림·영상 생성 API 를 쓰지 않고, HTML 장면 템플릿 11종을 HyperFrames(`npx hyperframes@0.9.72 render`)로 렌더한다.
  나레이션은 Edge 현수(1.2배속)이고, 자막·효과음·배경음악(Lyria 곡)이 붙는다. **렌더비는 0원이다.**

## 왜 명세와 다른가
- 기존 표현방식은 그림 생성(comic·photo)이 전제다. 운영자 지시(2026-11-24)는 "하이퍼프레임으로 만드는 체계가 좋다 — 리포트 영상도 이렇게"였다.
  근거는 손으로 만든 3편(`content_samsung_auto_2027/`)이다.
- `VIDEO_VERSIONS`(논문·리포트 공용, 엣지 미러)에는 넣지 않았다. 대신 `config.REPORT_ONLY_VERSIONS` 에 넣었다.
  공용 정규화가 미허용 버전을 기본 버전으로 바꾸고 그림 게이트를 돌리기 때문이다.

## 지키는 원칙
- LLM 은 템플릿 이름과 칸 글자만 고른다. 자유 HTML 은 쓰지 않는다.
- 칸 숫자는 컷 `source_facts` 의 사실 문장에 **단위째** 있어야 한다(`schema.number_gate`). 없으면 그 컷을 숫자 없는 설명 카드로 바꾸고 경고를 남긴다. 차단은 하지 않는다.
- 출처 쪽수는 Fact Sheet `source_page` 로 코드가 만든다. 끝 출처 카드(제목·증권사·"투자 권유 아님")는 리포트 행에서만 채운다.
- 한국어만 렌더한다. 승인 라우트가 motion 의 언어를 ko 로 고정한다.

## 되돌리는 법
- 대시보드에서 숨기려면 `web/lib/versions.ts` 의 motion 항목을 지운다. 엔진 분기는 남아도 해가 없다.
- 기본값 전환은 별도 커밋이다. 되돌릴 때는 그 커밋만 revert 한다.
