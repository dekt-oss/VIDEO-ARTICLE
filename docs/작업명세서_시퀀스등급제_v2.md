## 1. 아키텍처 원칙

1. **canonical router 를 우회하지 않는다.** effective_tier 는 `resolved_visual_plan` 을
   읽지, 시퀀스 소속에서 직접 오지 않는다(P0-1).
2. **VideoSpec = 단일 실행 계약.** provider 는 tier·model·길이를 재판단하지 않는다(P0-2).
   예상 스펙 = 발주 스펙 = 기록 스펙.
3. **품질을 몰래 바꾸는 코드 금지.** 남는 상한은 전부 [경고 | 발주 전 fail-fast]다(P0-3·4).
4. **새 필드는 소비자와 같은 PR 로.** 만들어 놓고 한쪽만 연결이 여덟 번 나온 저장소다 —
   temporal_plan 은 prompt builder 와, cost_plan.sequences 는 web 배선과 함께 간다.
5. 기본값에는 표시(`tier_defaulted`·`tier_reasons`). 판정 불가 ≠ 실패.

### Phase A — config: 등급표 + Quality Profile (순수 상수)

```python
SEQUENCE_TIERS = ("invest", "standard", "economy")
# Quality Profile — 길이만이 아니라 연출 계약까지가 등급이다(기획 §4)
TIER_PROFILE = {
  "invest":   {"clip_sec": 8, "min_beats": 2, "max_beats": 3, "camera_plan": "required",
               "state_change": "required", "candidates": 2},
  "standard": {"clip_sec": 4, "min_beats": 1, "max_beats": 2, "camera_plan": "optional",
               "state_change": "optional", "candidates": 1},
  "economy":  {"clip_sec": 4, "min_beats": 0, "max_beats": 1, "camera_plan": "none",
               "state_change": "none", "candidates": 1},
}
TIER_VIDEO_MODEL = {t: VEO_MODEL for t in SEQUENCE_TIERS}   # v2 전부 Lite. Fast 는 표만 교체
SEQUENCE_TIER_VERSIONS: tuple = ("photo",)                   # 등급제 적용 버전(리포트는 실측 후)
VIDEO_FIRST_VERSIONS: tuple = ()                             # Phase F 전까지 빈 튜플
MAX_CHAIN_DEPTH = 2                                          # I2V 재-anchor 깊이(기획 §10)
```

- DoD: 상수 + 순수 함수(`tier_profile(tier)`) + 테스트. **B 와 같은 PR**(원칙 4).

## 구현 중 실측으로 잡은 결함 5건

전부 "코드를 읽어서"가 아니라 **돌려서** 나왔다.

1. **새 kwarg 무조건 전달 → 조용한 스틸 폴백.** 옛 시그니처 호출부에서 TypeError 가
   나고 재시도 루프가 삼켰다(테스트 3건 실패로 드러남). 등급 없으면 인자를 안 넘긴다.
2. **`None == None` 을 연쇄로 읽음.** 리뷰 §11 이 경고한 함정을 구현에서 그대로 밟았다.
   리뷰 명세로 **먼저 쓴 테스트가 내 구현 오류를 잡았다.**
3. **연출 계약이 실사형에 안 갔다.** `_VIDEO_CLIP_GUIDANCE` 에만 넣었는데 photo 는
   `_PHOTO_VIDEO_CLIP_GUIDANCE` 를 쓴다 — **등급제를 켜는 바로 그 버전**에 계약이
   빠질 뻔했다. 독립 상수로 뽑아 세 경로가 같은 문자열을 쓰게 했다.
4. **원장이 후보 비용을 절반으로 거짓말할 뻔.** 2개를 뽑았는데 1행만 남기려 했다.
   `attempt_no` 로 후보마다 한 행(마이그레이션 0).
5. **`tiers: undefined` 로 객체 모양 변경.** 기존 `orderCost` 테스트가 잡았다.
   등급제 밖 버전에는 키 자체를 넣지 않는다.
