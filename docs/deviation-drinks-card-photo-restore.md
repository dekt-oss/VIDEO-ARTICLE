## 2. 고친 것

- **엔진:** PR 126 의 사진형 배치(`engine/drinks_cards_photo.py`)·캡션 조립(`engine/drinks_caption.py`)·로고·카드 배경 사진 주문(`drinks_paid.card_image_item`, 4:5, raw prompt)을 지금 main 위에 다시 얹었다.
  main 이 그 사이 더한 것은 그대로 둔다: 렌더 직전 카드 글 검사(R7), 재시도 없는 유료 그림 호출(`gemini_image_once`, R1), 카드 릴스(0065).
- **릴스:** 사진형이면 릴스 프레임을 글자 카드 틀로 다시 그리지 않고, 이미 그린 사진형 페이지를 9:16 화면에 얹는다(첫 장 위 띠에 훅, 마지막 장에 저장/보내기 한 줄). `drinks_card_reel.draw_photo_frame`.
- **초안 작성기:** `config.DRINKS_CARD_LAYOUT = "photo"`(기본). 제목에 `[핵심어]` 한 쌍, 본문 2줄, 출처 장 말고 모든 쪽에 영어 `image_prompt`. 코드 검사가 막는다(`photo_prompt_missing`·`photo_prompt_not_english`·`photo_body_lines`·`photo_highlight`). `text` 로 바꾸면 예전 글자 카드.
- **DB(0077):** 0056 을 지금 정의 위에 — `drinks_is_photo_plan`, `drinks_estimate_render`(사진 쪽 계산), `drinks_request_render`(사진형 카드도 유료 허용), `drinks_validate_plan`(0065 + 사진형 칸 보존).
- **스튜디오 연결(0077):**
  - 버전 화면이 사진 금액을 보여 준다(`$0.16 · 배경 사진 4장(AI 생성, 유료)`). [생성]이 그 금액(`approve_usd`)을 보내고, 서버가 지금 예상과 대조해 **같거나 크면** 그 초안 전용 결재(그림만·1일·상한=그 금액)를 열고 유료 제작을 요청한다. 금액이 없거나 작으면 `spend_confirm_required` 로 **확정도 구매도 하지 않는다**(한 트랜잭션). 이미 산 사진은 예상에서 빠진다(다시 사지 않는다).
  - 확정된 글자 카드 결과 화면에 **[사진형으로 다시 만들기]** — 같은 확정 근거로 새 초안을 쓴다(이번 주 AI 초안 한도 안). 옛 결과는 새 초안이 확정될 때까지 그대로. 새 초안 [생성]은 `drinks_plan_action` 제출·승인을 거친다(검사 그대로).
  - 워커: 형식이 card 인 대본 요청은 확정 뒤 요청도 카드 작성기로 간다.

## 4. 남은 결정(운영자)

1. 0077 운영 적용 + 이 PR 머지.
2. 사케 카드 배경 사진 구매 — 새 초안이 정해지면 쪽 수 × $0.039(6쪽이면 $0.23).

   설명형 공급자 호출은 별도 스위치(`DRINKS_EXPLAINER_PROVIDER_SEND_ENABLED`, 기본 꺼짐)가 막고 있어 키를 줘도 켜지지 않는다.
