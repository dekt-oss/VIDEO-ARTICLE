# 범위 이탈 기록: 수집·채점 무인 스케줄 실행 (GitHub Actions cron)

> CLAUDE.md 작업 규칙 6 — 명세/범위와 충돌하는 구현 결정은 `docs/` 에 근거를 남긴다.

## 무엇이 바뀌었나
`engine.yml` 의 `schedule: cron "10 21 * * *"`(UTC=KST 06:10) 주석을 해제해,
**매일 자동으로 수집→채점→초안 큐 처리**가 돌게 했다. 기존에는 `workflow_dispatch`(수동)
전용이라 사람이 버튼을 눌러야만 실행됐다.

## 왜 (문제)
운영자 확인 결과, 라이브 배치가 **2026-07-02 이후 멈춰 있었다.** 원인은 파이프라인 결함이
아니라 **자동 실행이 꺼져 있었기 때문**이다(엔진 실행 4회 전부 수동, 마지막 07-02).
"일별로 데이터가 올라오게 해달라"는 요청을 충족하려면 무인 스케줄이 필요하다.

## CLAUDE.md 범위와의 충돌
CLAUDE.md 범위는 "cron 무인 실행/클라우드 엔진 배포"를 P2 이후로 **명시적 제외**한다.
daily cron 은 이 경계를 넘는다.

## 결정
운영자가 "일별로 데이터가 올라오면"을 전제로 요청했으므로 daily cron 을 활성화한다.
수집·채점 비용은 Gemini 무료 등급 기본이라 무인 실행 비용 부담이 낮다.

## 트레이드오프 / 주의
- **스케줄 실행은 `workflow_dispatch` inputs 를 못 받는다** → env 에 `${{ inputs.x || '기본값' }}`
  를 둬서 무인 실행에서도 문서화된 기본값(윈도우 10일, 채점 150편, gemini-2.5-flash)으로 동작.
- **필수 Secret**(`GEMINI_API_KEY`, `SUPABASE_SERVICE_KEY`)이 있어야 실행된다. 과거 수동 실행
  3회가 성공했으므로 이미 설정돼 있다.
- **멱등**: 수집은 `external_id` upsert, `daily_batch` 는 당일 재생성이라 하루 여러 번 돌아도 안전.
- **중단 방법**: `engine.yml` 의 `schedule:` 블록을 다시 주석 처리(또는 Actions 에서 워크플로 disable).
