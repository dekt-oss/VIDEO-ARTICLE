## 0-A. 논문 원문 확보율 — **GO** (63% ≥ 50%)

대상: 최근 **낙점(picked) 논문 100편**(decisions.status='picked', 낙점 시점 역순).
체인: arXiv(네이티브 HTML → ar5iv → PDF) → OpenAlex OA(locations[] 전체) → PMC(Europe PMC JATS)
→ Unpaywall. 판정은 코드가 글자 수로 한다(`engine/paper_source.classify_depth`).

| 항목 | 값 |
|---|---|
| 대상 | 100편 |
| 확보(full_body + partial_body) | **63편 (63%)** |
| GO 기준 | ≥ 50% → **통과** |
| full_body (≥8,000자) | 58편 |
| partial_body (2,000~8,000자) | 5편 |
| abstract_only(미확보) | 37편 |
| 파서 실패 | **0건** |

| provider | 편수 | | content_format | 편수 |

PMC·Unpaywall 이 0건인 것은 그 경로가 죽어서가 아니라 **앞 단계에서 이미 잡혔기 때문**이다
(체인은 앞에서 본문이 잡히면 뒤를 부르지 않는다). 뒤 두 경로는 코드에 남겨 둔다 — 확보처
구성이 바뀌면(예: 의학 비중이 늘면) 그때 실제로 일한다.

### 식별자별 — 여기가 이번 실측의 핵심

| 식별자 | 확보 | 비율 |
|---|---|---|
| `arxiv:…` | 21 / 21 | **100%** |
| DOI | 42 / 79 | **53%** |

미확보 37편은 **출판사 페이월에 몰려 있다**. 표본: PNAS 3건, Science 2건 — 랜딩 페이지가
Cloudflare 403 이고 OA 사본이 없다. 즉 실패는 파서 문제가 아니라 **접근권 문제**다.
(엠바고가 풀리면 나중에 OA 가 되는 일이 흔하다 → 그래서 확보 실패는 DB 에 박제하지 않는다.
`engine/paper_source.store_packet` 주석 참조.)

### 0-A 판단

- **논문 라인 설명 엔진을 진행한다**(Phase 1 이후). 다만 **절반 가까이는 계속 초록만 보게 된다** —
  파이프라인은 `source_depth` 에 따라 두 갈래로 갈라져야 하고, 초록만인 논문에 원문 기반
  게이트를 걸면 그 논문들이 통째로 막힌다.
- arXiv 계열이 100% 라는 것은 **선별 단계의 유인**이기도 하다. 같은 점수면 원문이 열리는
  논문을 고르는 편이 완성 영상 품질에서 유리하다 — 다만 이번 범위에서 채점 가중치는 건드리지 않는다.

## 0-B / 0-C. 같은 논문 3안 비교 — **NO-GO** (C−A = +2.0, 기준 +4)

대상: 0-A 에서 원문을 확보한 논문 20편 중 **16편**(4편 탈락: Gemini 503 3건 + 출력 절단 1건).
백엔드: 세 갈래 모두 `gemini-2.5-flash`(추출·설명) + `gemini-2.5-pro`(대본), Anthropic 폴백 꺼짐.
같은 논문에 A/B/C 를 모두 돌리고, 심사관이 **섞인 익명 라벨**로 한 자리에서 채점했다.

### 판정

| 지표 | 심사관 flash | 심사관 **pro** | 명세 기준 | 판정 |
|---|---|---|---|---|
| **C − A** | +0.44 | **+2.00** | ≥ +4 | ❌ **NO-GO** |
| C − B | +0.62 | +0.69 | ≥ +2 (설명 모델 유지) | ❌ 접는다 |
| B − A | −0.19 | +1.31 | — | 약한 플러스 |
| 장식형 컷 비율(A/B/C) | .25/.27/.28 | .44/.43/**.41** | C 가 더 낮아야 | △ 차이 미미 |
| 평균 총점(A/B/C) | 13.3/13.1/13.7 | 14.5/15.8/**16.5** | 20점 만점 | |

**pro 심사관 기준 방향은 일관되다 — A < B < C.** 최고점 횟수 A 3 / B 5 / **C 8**,
C−A 는 16편 중 **12승 1무 3패**. 설명 모델이 겨냥한 축에서도 이겼다:
`mechanism_depth` A 0.69 / B 0.75 / **C 1.06**, `evidence_attribution` 1.12 / 1.44 / **1.50**.

**그런데 크기가 게이트의 절반이다.** C−A = +2.00 ± 3.41(표준편차), 표준오차 0.85 →
95% 신뢰구간 대략 **[+0.3, +3.7]**. 표본을 40편으로 늘려도 구간 상단이 +4 에 닿기 어렵다.
즉 "더 재면 통과할 수도" 가 아니라 **이 설계로는 +4 를 못 넘는다**가 지금까지의 답이다.

### 이 실측에서 가장 중요한 숫자 — 심사관을 바꾸면 결론이 뒤집힌다

**같은 시안을 두 심사관이 채점한 점수차가 평균 3.81점(최대 10점)이다.** 재고자 한 효과(+2.0)보다
측정 잡음이 크다. flash 로 재면 C−A = +0.44(효과 없음), pro 로 재면 +2.00(방향 뚜렷) —
같은 산출물, 같은 루브릭인데 결론이 갈린다.

그래서 이 실측의 결론은 **"C 가 A 보다 확실히 낫다/아니다"가 아니라 "명세가 요구한 +4 만큼
좋지는 않다"** 이다. 후자는 두 심사관 모두에서 성립한다.

### 갈래별 설계

- **A** = 현행(초록 → Fact Sheet → 대본)
- **B** = 전문 주입(초록+원문 → Fact Sheet → **현행 대본 프롬프트 그대로**)
- **C** = 설명 모델(B 의 원장 → Scientific Explanation Model → 그 설명 단위를 소비하는 대본)

### 부수적으로 나온 것 (Phase 2 를 하게 되면 그대로 쓰인다)

- **인용 대조 통과율 0.74**(설명 단위가 "원문 인용"이라며 내놓은 구절 중 26%는 원문에 글자
  그대로 없다 — 번역·요약·재작성). 코드 대조가 실제로 걸러낼 물량이 이 정도다.
- **설명 단위 근거 부착률 1.0** — 모든 단계가 claim_id 나 인용 중 하나는 갖고 나왔다.
- **원장이 폭발한다.** 원문 30,000자를 주면 Fact Sheet 출력이 `maxOutputTokens` 16,384 를 넘고
  32,768 에서도 1편이 잘렸다. 운영에 올린다면 **출력 상한이 아니라 claim 개수에 상한**을 둬야 한다.
- 임상 RCT 처럼 기전이 보고되지 않은 논문에서는 설명 모델이 MECHANISM 을 **지어내지 않고**
  STRUCTURE/COMPARISON 으로 냈다 — D4(메커니즘 개수로 게이트하지 않는다)를 뒷받침한다.

### 실측 중 발견해 고친 결함 3건

1. **출력 절단으로 편이 통째로 날아갔다**(8192 → 16384 → 32768). 세 갈래 중 하나만 실패해도
   paired 비교가 성립하지 않는다. 커밋 `38abfde`.
2. **심사관에게 초록만 줬다** — 본문에서 정당하게 가져온 사실이 "초록에 없다"는 이유로
   환각 처리됐다(*"80%/75% 수치와 '0.5초 윈도우' 등 초록에 없는 구체 수치가 다수 등장해
   no_hallucination 0"*). 세 갈래 공통으로 원문을 주도록 고쳤다. 커밋 `c86b804`.
3. **1차 실행이 Anthropic 으로 돌았다** — 논문 초안을 실제로 만드는 것은 엣지 함수이고 거기는
   Gemini 다. 전량 Gemini 로 다시 돌렸다(운영자 지적). 커밋 `b994344`.
   ※ 그 과정에서 **Gemini 키가 로그에 평문으로 남는 것**을 발견해 헤더 전송으로 바꿨다(`31cb673`).

### 실측 조건에서 명세와 다르게 한 것

1. **백엔드 Gemini 고정**(운영 경로와 일치). 세 갈래 같은 모델 — 비교 대상은 구조이지 모델이 아니다.
2. **원문 주입 상한 30,000자**(운영값 60,000). 입력 토큰이 비용의 절반을 먹는다.
3. **n = 16**(20 목표). 탈락 4편은 Gemini 503 3건 + 출력 절단 1건.

### 루브릭 출처에 대한 정직한 기록

명세는 "v2 리뷰 §17 루브릭 10항목"을 쓰라고 지시하지만, **v2 리뷰 원문은 저장소에 없다**
(운영자 Downloads 보관, 명세 §13). 그래서 10항목을 명세 §9(성공·실패 조건)에서 재구성했다:
`discovery_clarity / mechanism_depth / causal_accuracy / scope_disclosure / evidence_attribution /
no_hallucination / reference_separation / visual_substance / narrative_cohesion / information_density`
(각 0~2점, 20점 만점). 원본 §17 과 항목이 다를 수 있다 — 운영자가 원문을 주면 대조한다.
