## 1. 아키텍처 원칙 (기획 P1~P5의 실행 번역)

1. **새 구조 금지.** 등급은 기존 `resolved_visual_plan.sequence_ref` 를 타고 돈다.
   컷 스키마·렌더러·조립은 건드리지 않는다.
2. **등급 판정의 입력은 구조 판정이다.** `sequence_is_progression()` 통과 시퀀스만
   invest(자기보고 차단). 판정 불가는 economy + `tier_defaulted: true`
   (§9-10 교훈 — 기본값도 정본으로 읽히므로 표시를 남긴다).
3. **조용한 강등 금지.** 상한이 등급 결정을 덮어쓸 때는 반드시 경고를 남기고
   ⑤ 에 보인다. 세 겹 상한 각각의 처리를 Phase C 에서 **전수** 명시한다 — 한 겹이라도
   빠뜨리면 실측 전례("개수를 풀었는데 초수가 다시 잘랐다")가 재현된다.
4. **비용은 관측이다.** 새 코드 어디에도 비용을 이유로 품질을 깎는 분기를 넣지 않는다.
   유일한 예외는 기존 잡 단위 `RENDER_BUDGET_CAP_USD`(폭주 최후선 — 그대로 둔다).

## 2. Phase 계획

### Phase A — config 등급표 (순수 상수, LLM·네트워크 0)

- `engine/config.py`:
  ```
  SEQUENCE_TIERS = ("invest", "standard", "economy")
  SEQUENCE_TIER_BY_ROLE = {MECHANISM_SEQUENCE: invest,
                           RESULT_SEQUENCE: standard, REALITY_ANCHOR: standard,
                           FRAMING: economy}          # 시퀀스 밖 컷 → economy
  TIER_VIDEO_MODEL   = {invest: VEO_MODEL, standard: VEO_MODEL, economy: VEO_MODEL}
                       # ★ v1.1 전부 Lite. Fast 는 D1 확정+단가 확정 후 표만 교체
  TIER_CLIP_MAX_SEC  = {invest: 8, standard: 4, economy: 4}
  ALL_VIDEO_VERSIONS: tuple = ()                      # D2 — Phase F 전까지 비워 둔다
  ```
- 함수: `video_model_for_tier(tier)` · `clip_cap_for_tier(tier)` · `tier_of(cut, header)`.
  `tier_of` 는 ①`sequence_ref` → 시퀀스 → ②구조 판정 통과 확인 → ③역할 → 등급.
  시퀀스 없음/판정 불가 → `("economy", defaulted=True)`.
- DoD: 순수 함수 + 테스트. 소비자는 다음 Phase 가 배선(이 Phase 단독 머지 금지 —
  "만들어 놓고 한쪽만 연결" 방지를 위해 B 와 같은 PR 로 간다).

### Phase B — 스펙·티어 소비 배선

- `generation_spec.video_spec`: `config.VEO_MODEL` 직접 참조 → `video_model_for_tier`.
  **VideoSpec 에 tier 필드 추가** — 캐시 키·원장에 들어가 등급 변경 시 재생성된다
  (의도된 무효화, `start_asset_hash` 전례).
- `providers/video.py::generate_clip`: `pick_clip_tier(max_sec=clip_cap_for_tier(tier))`.
- ★ **전수 조사**: `VEO_MODEL`·`VEO_CLIP_MAX_TIER_SEC` 전역 참조 6곳을 훑어 tier 경유로
  바꾸거나 "전역이 맞는 자리"임을 주석으로 남긴다. `python -m scripts.sweep_unwired`.

### Phase C — 조용한 강등 제거 (v1.1 의 심장)

세 겹 상한 각각에 대해 처리를 명시한다:

| 겹 | 현재 | v1.1 처리 |
|---|---|---|
| ① `enforce_mode_video_budget` (개수, 선착순) | 말없이 스틸 강등 | **삭제.** 개수 제한 없음 — 총액은 ⑤ 가 보여 준다 |
| ② `video_clips_max` 전역 캡 | 말없이 강등 | 등급제 적용 버전에서는 **경고로 전환** (`video_cap_exceeded:{n}`) — 강등하지 않는다 |
| ③ `video_budget_for` (초수·금액) | 지시서 단계에서 자름 | 등급제 적용 버전에서는 **관측으로 전환** — cost_plan 에 예상치만 싣고 자르지 않는다 |

- 등급제 적용 여부는 버전 단위 스위치(`SEQUENCE_TIER_VERSIONS`)로 — 만화식·설명판형은
  기존 동작 그대로(하위호환, D6 원칙).
- 모든 전환은 `mode_warnings` 에 남는다. ⑤ 가 이미 그 키를 본다(새 표면 금지).
- DoD: ESS 실측 지시서(`docs/review-2026-08-30/equity_real_directive_v2.json`) 재생 시
  **어떤 컷도 말없이 스틸로 떨어지지 않고**, 초과분이 경고로 보이는 것을 테스트로 박는다.

### Phase D — 시퀀스 비용 관측 + ⑤ 화면 (v1.1 의 목적지)

- `cost_plan.sequences[] = {sequence_id, role, tier, clips, video_sec, est_usd,
  tier_defaulted_count}` — `compute_cost_plan` 이 **렌더가 읽는 것과 같은** 등급
  판정(`tier_of`)에서 집계(§9-4 "같은 resolved plan" 원칙의 돈 버전).
- 원장: `generation_attempts.meta` 에 `sequence_id`·`tier`(컬럼 아님 — 마이그레이션 0).
- `web/` ⑤ 확인 모달: 장면별 표(장면 · 등급 · 클립 수 · 예상 비용) + 편 총액을
  눈에 띄게 + 경고(②③ 전환분) 표시. 조회는 `selectIn/selectAll` 만.
- ★ 예상 단가 셈은 `cost.unit_price` 단가표 하나에서 나온다 — ⑤ 숫자와 원장 숫자가
  다른 소스를 읽으면 반드시 갈라진다.

### Phase E — I2V 연쇄 경계를 world_ref 로 (전부-영상의 선행조건)

- 현재: 사이에 낀 스틸이 유일한 사슬 경계 → 전부 영상이면 영원히 안 끊긴다 →
  세계가 바뀌어도 앞 장면 마지막 프레임에서 이어 만든다(기획 R2).
- 변경: `render.py` 사슬 리셋 조건에 `world_ref 변화` 추가. 스틸 경계는 유지(동작 불변).
- DoD: 회귀 테스트 — 같은 world 연속 영상 컷은 잇고, world 바뀌면 끊는다.
  **Phase E 없이 `ALL_VIDEO_VERSIONS` 를 켜면 테스트가 실패하도록** 강제한다.

### Phase F — 전부-영상 스위치 (D2 확정 후)

- `ALL_VIDEO_VERSIONS` 에 버전을 넣으면 그 버전의 `motion_source` 기본이 video.
- 발주서 경로(`scripts/web_order`)도 같은 판정을 타는지 확인(무료 실측 경로 유지).

### Phase G — 실측

- ① **무료 (예상의 정확성):** `web_order` 발주서에 등급이 반영되는지(8s/4s 프롬프트) +
  ⑤ 예상 비용 대 조립 결과 대조. "예상을 보고 조절한다"는 예상이 맞아야 성립한다.
- ② **유료 (사전 승인 필수):** 논문 photo 1편 — invest 8s 클립이 기전 표현을 실제로
  개선하는지 눈으로. 예상 ~$2.80/편. 개선이 없으면 **8s 의 근거가 사라진다** —
  등급표를 되돌리고 기록한다.
- ③ 실렌더 원장(`sequence_id`·`tier` 포함) vs ⑤ 예상 대조 → **여기서 나온 실제
  지출 데이터가 v2(비용 강제) 착수의 입력**이다.

## 4. 테스트 계획

- 등급 판정: 역할→등급 · 시퀀스 없음→economy+defaulted · 구조 판정 미통과→economy.
- 조용한 강등 제거: 등급제 버전에서 상한 ①②③ 어느 것도 말없이 컷을 바꾸지 않는다.
  **선착순 회귀 방지** — 기전 시퀀스가 마지막 컷이어도 8s video 로 남는 테스트.
- 하위호환: 등급제 미적용 버전(만화식 등)은 기존 상한 동작 그대로.
- 캐시: tier 변경 → VideoSpec 해시 변경.
- 연쇄: world 경계 리셋(Phase E) + 스위치-선행조건 강제.
- 관측 정합: cost_plan.sequences 합계 == 컷별 예상 합계 == 같은 단가표.
- 실데이터: ESS 지시서 재생(Phase C DoD). 기존 1,325개 회귀 없음.

## 6. 적대적 자기리뷰 (구현 완료 후 답할 것)

- 세 겹 상한 중 **말없이 강등하는 경로가 한 곳이라도** 남아 있는가?
- `VEO_MODEL`·`VEO_CLIP_MAX_TIER_SEC` 직접 참조가 남아 있는가?
- ⑤ 의 예상 숫자와 원장 숫자가 같은 단가표·같은 등급 판정에서 나오는가?
- 모델이 라벨만으로 invest(8s)를 얻을 수 있는가?
- tier 가 캐시 키에 들어갔는가 — 등급을 바꿨는데 옛 클립이 재사용되지 않는가?
- 전부-영상에서 world 경계 없이 사슬이 이어지는 경로가 남아 있는가?
- 만화식·설명판형이 등급제 코드 경로에 우연히 들어오지 않는가?
- `cost_plan.sequences` 를 만들어 놓고 ⑤ 가 실제로 그리는가(한쪽만 연결 방지)?
