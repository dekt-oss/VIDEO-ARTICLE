**운영자(2026-11-08):** "자동생성이 안 되는 건 애초에 리스트에 없어야", "중복소재가 왜 이렇게 많아", "근거 확인 화면이 너무 복잡해 — 아주 매우 단순화", "소재 고르기와 콘텐츠 스튜디오 제대로 통합".

## 바꾼 것
- **통합:** `/drinks/topics` 를 없애고 `/drinks/studio` 하나로. 옛 주소는 middleware 가 넘긴다(`legacyTopicsRedirect`). 내 소재·밈 카드·보류·제외는 `?tab=`, 이번 주 한도·손으로 넣기는 ① 화면에 붙였다. 왼쪽 메뉴에서 "소재 고르기" 삭제.
- **목록(`web/lib/drinks/studioList.ts`, 모델 호출 없음·0원):**
  - 빼는 것: 점수·주종을 모르는 후보, 취향 묻기, 근거 0건, 자동 복구 대상이 아닌 이유로 멈춘 소재(초안 없는 것만), `[테스트]` 소재.
  - 묶는 것: 주종이 같고 (희귀 낱말 겹침 ≥ 0.24 또는 같은 주제 목록) 이면 하나로. 이미 있는 소재와 같은 이야기면 후보에서 뺀다.
  - 후보를 지우지 않는다 — 화면 목록에서만 뺀다. 상위 50묶음까지 근거를 세므로 그 아래 후보는 안 보인다.
- **근거 화면(`EvidenceTab`):** 기본은 문장 + ✓/⚠ + [원문 보기] + [빼기]. 출처 추가·칸별 수정·검토 기록은 접힌 [직접 고치기] 안에 그대로 있다.
- 설명형(영상) 초안만 있는 소재는 스튜디오가 처리하지 못해 눌러도 아무 일이 없었다 → [설명형 초안 이어보기]로 작업공간에 잇는다.
