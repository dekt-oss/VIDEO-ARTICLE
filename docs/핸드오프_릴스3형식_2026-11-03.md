## 함정

- **마이그레이션 번호 순서를 믿지 않는다.** 0057·0058 이 빠진 채 0059~0061 만 적용돼 있던 적이 있다. `supabase_migrations.schema_migrations` 와 파일 목록을 대조한다.
- **`gh pr merge` 와 운영 쓰기는 자동 권한 검사에 막힐 수 있다.** 우회하지 말고 사장님에게 묻는다.
- **pytest 는 web 소스도 grep 한다.** 웹만 고쳐도 전체를 돌린다. `web/lib/drinks/officialSources.ts` 는 `engine/config.py` 와 시험으로 묶여 있다.
- **수집기 연결**(`engine/drinks_fetch.py`): 검사를 통과한 IP 를 IPv4 부터 차례로 시도한다. 전체 공개 주소 검사와 연결 직전 재해석은 유지해야 한다.
