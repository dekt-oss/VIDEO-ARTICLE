## 함정

- **운영 화면:** 내장 브라우저는 운영자 잠금에 걸린다. 키를 입력하지 않고, 잠금이 풀린 사용자 Chrome 에서 읽기만 한다.
- **시험 전에 `web` 에서 `npm ci`:** 없으면 DB 시험이 건너뛰어져 통과처럼 보인다(이번에 12건 → 4건).
- **웹만 고쳐도 pytest 전체:** 파이썬 시험이 웹 소스를 읽는다. 전체 약 9분이다.
- **웹 시험 명령:** `npm test` 는 없다. `web` 에서 `node --test lib/*.test.ts lib/work/*.test.ts lib/drinks/*.test.ts`.
- **`gh pr merge` 와 운영 쓰기**는 자동 권한 검사에 막힐 수 있다. 우회하지 않고 사장님에게 묻는다.
- **마이그레이션 번호 순서를 믿지 않는다.** 적용 전에 운영 적용 목록과 파일을 이름으로 대조한다.
- `meme_refine_rehearsal` 산출물은 날짜와 무관하게 `docs/preview-2026-11-02/` 로 간다. 옛 결과로 착각하지 않는다.
