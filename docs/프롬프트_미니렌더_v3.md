## 판정 기준 — 무엇이 통과인가

리뷰 §19 가 정한 것입니다. 숫자로 판정하지 않고 **눈으로** 봅니다.

| | 통과 | 실패 |
|---|---|---|
| 개체 동일성 | 같은 사람/같은 물체로 보인다 | 단계마다 다른 사람/다른 물체가 된다 |
| 세계 유지 | 배경·카메라·조명이 그대로 | 장면이 통째로 바뀐다 |
| 진행 | 단계마다 눈에 보이게 달라진다 | 사실상 같은 그림 |
| 수치 | 그림에 숫자가 없다 | 숫자·퍼센트가 글자로 박힌다 |
| 글자 | 아무 글자도 없다 | 라벨·로고·캡션이 나온다 |

**하나라도 실패하면 그 이유를 알려주세요.** 프롬프트 문구를 고칠지, 코드를 고칠지
판단이 갈립니다 — 채팅에서도 깨지면 프롬프트 문제이고, 채팅에서는 되는데 코드에서만
깨지면 배선 문제입니다.
