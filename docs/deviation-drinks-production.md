# 주류 공장 C단계 — 영상 우선·카드뉴스 병행 제작 (2026-10-23)

명세 §7(production_jobs·media_assets·asset_manifests·deliverable_assets·output_reviews)·§8.3·§12.
마이그레이션 `0053_drinks_production.sql`(0052 위, 어디에도 미적용). 브랜치 `claude/drinks-factory-phase-c`.

## 흐름

선정 소재 + 승인된 근거 → 공통 기획(A) → 영상 / 카드 제작안(A, 형식별 독립 승인) → **렌더 요청**(입력 고정) →
워커가 렌더 → **불변 파일 묶음**(manifest) → **최종 파일 검수**(형식별, 사람). 공유되는 것은 핵심 주장·근거·브랜드뿐이고,
대본·장면·페이지·버전·승인은 형식마다 따로다 — 카드만 다시 렌더해도 영상 묶음·승인은 그대로다(테스트·e2e 확인).

## 표(0053)

| 표 | 지키는 것 |
|---|---|
| `drink_production_jobs` | 입력 = 제작안 승인 해시 + 근거 승인 해시 + 렌더러 버전. 같은 제작안·같은 입력의 활성 작업 1개(중복 요청 = 같은 작업). 임대 토큰 없으면 기록 불가, 임대 만료 = 실패(늦은 결과 저장 안 함). 끝난 작업 불변 |
| `drink_media_assets` | 파일 불변(상태만 stored→deleting→deleted). 저장 위치는 `drinks/` 또는 `local:` 만. 같은 위치에 다른 내용 금지. 검수 대기·승인 묶음의 파일은 정리 상태로 못 바꿈 |
| `drink_asset_manifests` · `drink_manifest_assets` | 묶음·구성 불변. 영상 = 최종 영상 1 + 커버 1, 카드 = 제작안 페이지 수만큼 1..n 연속. 이 작업이 등록한 파일만 |
| `drink_output_reviews` | 묶음 1:1. pending → approved / changes_requested / blocked. 승인 = 형식별 체크리스트 전부 확인 + **그 순간** 제작안 미차단·근거 유효(트리거가 직접 UPDATE 도 막음). blocked 는 풀 수 없음 |
| `drink_cost_entries` | append-only. 작업·시도·공급자·모델별. 공유 파일 비용은 파일당 한 번 |
| `drink_output_validity`(뷰) | 승인 기록과 **지금 사용 가능**을 따로 — 근거 철회 뒤 승인 묶음은 "승인됨·지금 사용 불가" |

근거 철회·권리 변경 처리: 대기 작업은 워커가 시작할 때 취소(비용 쓰기 전), 진행 중 작업은 파일·비용을 보존하고 검수를 blocked 로,
이미 승인된 묶음은 기록을 남기고 현재 사용 불가로 표시. 렌더 요청도 그 순간 거부한다.

## 영상 — 기존 엔진 재사용

- 어댑터 `engine/drinks_render.py::plan_to_directive` 가 영상 제작안(scenes[])을 엔진 지시서 모양(cuts[])으로 바꾸고
  `render.render_directive_local` 을 부른다 — 엔진의 TTS → 컷 mp4(Ken Burns·패닝) → ASS 자막 → 조립·음량 정규화를 그대로 탄다.
- 논문 전용 경로를 우회하지 않고 **닿지 않게** 했다: directive_id 없이 부르므로 자산 캐시·논문 원장·논문 표에 쓰지 않는다.
  `version_type='image_sequence'`(photo 는 영상 생성 필수 경로라 쓰지 않음), `motion_source`·실사 계약 필드를 켜지 않는다.
- 엔진에 없던 것(신규): 커버(Pillow), 장면 유형 표기, 결과 검사(ffprobe 해상도·길이·오디오, 무음 감지, 글자 잘림, 없는 글자).
- **장면 유형 표기**: 장면 카드마다 "연출 장면 · 실제 제품·시설 촬영 아님" / "설명용 도해 · 실제 공정을 단순화함" / "정리 카드".
  검수 체크리스트에 "장면 유형이 보인다"·"실제 제품·제조 과정으로 오해될 장면이 없다"가 필수 항목이다.

## 유료 실행

**꺼져 있다.** 렌더 요청의 `paid` 는 `paid_disabled`(예산 미설정)로 거부되고, 워커는 유료 공급자(이미지·영상·유료 TTS)가 켜져 있으면
렌더를 거부한다. 지금 렌더 = 로컬 대체 이미지(Pillow 장면 카드) + 무료 TTS(edge-tts) + ffmpeg. 비용 원장에는 $0 기록이 공급자별로 남는다.
유료 그림으로 바꿀 때 쓸 문장은 컷의 `visual_prompt` 에 이미 들어 있다(지금은 쓰이지 않음).

★ **대체 이미지 렌더는 목표 화풍(3D 도해·실사감·시네마틱) 품질 검증이 아니다.** 검증된 것은 제작안 → 장면·음성·자막·합성 → 세로 영상·커버

- 파일은 비공개 버킷 `drinks` 의 `drinks/{job}/…`(Supabase) 또는 로컬 검증 폴더(`local:`). 업로드는 upsert 하지 않는다(덮어쓰기 금지).

  주류 파일이 걸리지 않음을 **드라이런 테스트**로 못박았다(`tests/test_drinks_gc_guard.py`, 실제 삭제 0). 주류 파일 정리는 아직 연결하지 않았다.
- 버킷은 0053 이 storage 스키마가 있을 때만 만든다(비공개).

## 사진형 카드뉴스 "card-photo-v1" (2026-10-27, 운영자 승인 — 생존주의형)

시제품(Node/sharp, `2026-10-27 위스키 물`)을 엔진(Pillow)으로 옮겼다. 글자 카드(`card-v1`)는 그대로 두고, 제작안이 고르면 사진형으로 그린다.

- **고르는 법**: `plan.layout == "photo"` 또는 `plan.template_version == "card-photo-v1"`. 그 밖은 예전 그대로(바이트 동일). 렌더 qa 의 `template_version` 이 `card-photo-v1`.
- **쪽 필드**(`plan.pages[]`): 기존 `position`·`role`·`heading`·`body` 에 더해
  - `image_prompt` — 영어 그림 지시문(유료 구매용). 없으면 그 쪽은 어두운 바탕으로 그리고 qa 경고 `photo_missing`(실패하지 않는다).
  - `photo_shift` — 사진 세로 자르기 이동(px, 음수 = 사진 위쪽이 더 보임. 시제품 표지 `-110`).
  - `kicker`·`category`(표지 전용) — 맨 위 작은 줄 / 제목 위 강조색 소제목(좌우 가는 줄).
  - 제목(`heading`) 안의 `[대괄호]` = 강조색(#F5B840, `BRAND["key"]`). 줄 바꿈은 낱말 단위라 한국어 낱말 가운데서 끊지 않고, 강조 구간이 여러 줄에 걸쳐도 이어진다. 제목 3줄·본문 2줄 상한을 넘으면 `text_truncated`.
  - 출처 장(`role == "source"`): 본문 줄(없으면 `job.sources`) + 팔로우 안내(`@핸들`, 기본 `sooljjerigo`, `DRINKS_IG_HANDLE`) + 하단 고지. **주류 경고 문구는 출처 장에 항상 둔다.** "생성형 AI 이미지 포함" 줄은 산 그림이 하나라도 있을 때만.
