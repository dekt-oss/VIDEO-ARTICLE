## 0. 정정 — 「술 수업」 핸드오프(2026-11-26)의 연결 대상

11-26 문서는 리포트 라인의 `engine/motion` 구조를 다시 쓰라고 했다. 그 뒤 **주류 전용 하이퍼프레임 백엔드 `engine/hf_render.py`**
(템플릿 `hf_templates/<이름>/` + 데이터 + ledger 음원 → mp4, 실패는 `HfRenderError`, 라이브러리 로컬, −14 LUFS 정규화)가
PR #198 로 들어왔다. **두 형식(술 수업·술 해부) 모두 `hf_render.py` 위에 얹는다.** `engine/motion` 은 참고만 한다.
하이퍼프레임 버전은 `config.HF_HYPERFRAMES_PKG`(= `MOTION_HYPERFRAMES_PKG` = 0.9.72) 하나를 쓴다 — 두 정답 샘플 모두 0.9.72 로 렌더·검사했다.

## 3. 장치 계약 (샘플 그대로 구현한다)

### 3-1. 세계와 카메라
- 편은 **세계** 2~5개로 나뉜다(샘플: 항아리 → 체 → 잔 → 퀴즈). 세계 안에서는 장면을 끊지 않고 **카메라**가 움직인다.
  세계와 세계 사이만 0.15~0.2초 흐림 교체.
- 카메라 = 세계 SVG 안 `#<세계>-cam` 묶음의 `x·y·scale`(기준점 0,0). 초점 (fx,fy) 를 화면 (cx,cy)=(540,730) 에 배율 s 로:
  `x = cx − s·fx, y = cy − s·fy`. 다이브 1.0초 `power2.inOut`, 빠지기 0.8초, 옆 이동(패닝) 0.8초. 샘플 다이브 배율 2.2·1.45, 끝 살짝 밀기 1.15.
- **창문**: 그림 칸을 `clip-path: inset(424px 0 884px 0)`(화면 y 424~1036)로 자른다. 카메라가 밀어도 제목·말풍선을 덮지 않는다(1판 실패 사례).

### 3-2. 2.5D 그림 규칙 (`tools/art25.py`)
- 빛은 **왼쪽 위**. 원통 면은 가로 그라데이션(어두움 → 밝음(왼쪽 22~36%) → 중간 → 어두움). 아래쪽 그림자 덮개(세로 그라데이션).
- 윗면·바닥·층 경계는 **타원**, 세로 반지름 = 가로 × `PERSP = 0.17`.
- 회전체는 **단면 곡선 `profile(y)` 하나**로 바깥선·안쪽선·층 타원 폭을 모두 만든다(모양이 서로 어긋나지 않게). 옹기: 목 140 → 어깨 252 → 바닥 157.
- **단면 = 앞 절반 제거**: 안쪽 벽(그라데이션) → 바닥 타원 → 뒤쪽 입술(위쪽 반호) → 내용물(안쪽 곡선 clip) → 잘린 벽 두께(바깥선을 두께 2×WALL 로 긋고 바깥 곡선으로 clip) + 결 점.
- 닫힌 물체(훅·반복 재생 장면) 위에 단면을 미리 그려 두고, 닫힌 껍데기를 치워(`x −70`, 투명) 단면을 드러낸다. 뚜껑은 들려 날아간다.
- 층 = 앞면(사각, 안쪽 clip 으로 잘림) + 표면 타원(조금 밝은 색, 흰 테두리 35%).
- 받침·체·사발·국자·잔·유리잔·계기판도 같은 규칙(두께 있는 테, 원근 격자, 굽, 표면 거품, 반사선). 손은 아직 단순 — 개선 대상.

### 3-3. 토큰
- 원리를 **작은 입체 조각이 바뀌고 움직이는 것**으로 보여 준다. 사슬: `grain:전분 → sugar:단맛 → drop:술 + bubble:탄산`.
- 같은 자리에서 0.25초 교차 페이드로 변신, 기포는 위로 1.1초 오르며 사라짐. 변신이 시작될 때 **범례 칩 줄**(아이콘 + 이름 + 화살표)이 하나씩 뜬다.
- 토큰 모양은 편 전체에서 고정(같은 성분 = 같은 모양·색). 새 주제의 토큰(효모·당화효소·에스테르 등)은 사람이 그려 등록하고 LLM 은 목록에서만 고른다.

### 3-4. 시간 조절 HUD
- 왼쪽 위(84, 446) 단계 표시 `▶ 실제 시간 → ⏩ 빨리 감기 ×10 → ×1,000 → ×20,000`(0.35초씩) → 사건이 끝나면 `⏸ 다 익음`.
  오른쪽 위 원형 계기(발효)가 그 문장 동안 0 → 100% 찬다. 계기 글자 밑엔 어두운 받침(밝은 그림 위 명암 문제 해결).
- 숙성(위스키·사케)은 같은 장치로 `⏩ ×100,000 · 3년차`, 증류는 `‖ 슬로모션 1/240`. 표시 단계 글은 근거에 맞춰야 한다(지어낸 일수 금지 — 샘플은 일수를 안 씀).

### 3-5. 그 밖
- **이름표**: 부품을 가리키는 선 + 크림 상자(32px). 부품이 움직이면 따라간다. 글자는 인스타 안전 영역 안(좌우 65~1015, 위 269, 아래 1248).
- **의성어**: Wanted Sans 64~72px, 6px 잉크 테두리, 노랑. 효과음과 같은 프레임(보글보글·싹싹·톡톡).
- **갈림길 비교**: 같은 세계 안 두 갈래(국자로 떠낸 청주 잔 vs 통째로 묶는 괄호).
- **계기판**: 0~15 반원, 흔한 구간 강조(토마토), 범위 선(노랑), 바늘 `back.out(1.4)`.
- **숫자 퀴즈 + 반복 재생**: 마지막 세계에서 `퀴즈! … 1 · 2 · 3` → 끝 0.9초에 첫 프레임과 같은 닫힌 물체로 되돌아간다.

## 8. 함정

- **렌더가 무겁다**: 2.5D 그라데이션·clip 이 많아 check + render 를 한 백그라운드 명령에 넣으면 10분을 넘겼다(2026-11-28). 따로 돌린다. `HF_RENDER_TIMEOUT_SEC=900` 안에 렌더 단독 약 2분 30초.
- **같은 요소 반복 fromTo**: 경고(`gsap_repeated_fromto_without_baseline`). 다시 보이게 할 땐 `tl.set` + `tl.to`.
- **겹치는 등장·퇴장**: 기포·부스러기 퇴장 시작이 등장 끝보다 앞서면 `overlapping_gsap_tweens`. 퇴장은 등장 끝 뒤에.
- **밝은 그림 위 글자**: 카메라가 밀면 HUD·계기 글자 뒤가 밝아져 명암 경고. 글자에 어두운 받침.
- **확대 중 이름표**: 카메라가 밀린 동안 이름표를 띄우면 화면 밖으로 나간다(체 장면). 빠진 뒤에 띄운다.
- 「술 수업」 §9 함정(Edge 현수 rate, 자막 flex 안 `<b>`, 둥근 끝 점선, 안전 영역 0.9.72)도 모두 해당된다.
