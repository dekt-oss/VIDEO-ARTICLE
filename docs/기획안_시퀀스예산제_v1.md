## 0. 한 줄

**시퀀스(장면)를 품질의 단위로, 컷을 시간의 단위로** 나눈다. 원리 도해 시퀀스에는
긴 클립(8s)을, 브릿지에는 짧은 클립(4s)을 배정한다. 돈은 **강제하지 않고 관측한다** —
⑤ 화면이 시퀀스별 예상 비용을 보여 주고, 조절은 운영자가 등급표를 고쳐서 한다.

## 1. 왜 지금인가 — 실측 증거 3건

### ① 지금은 상한이 품질 결정을 **말없이** 덮어쓴다 (2026-08-31 ESS 지시서 실측)

`engine/directive.py:707` `enforce_mode_video_budget`:

```python
for c in cuts:
    if c.get("motion_source") == "video":
        if kept < limit: kept += 1
        else: c["motion_source"] = "still"     # ← 순서상 뒤면 무조건 강등
```

실측 로그: `컷 9 스틸로 강등`, `컷 10 스틸로 강등`. 중요도를 전혀 안 본다 —
기전 시퀀스가 뒤에 놓이면 그게 강등된다. 게다가 상한이 **3겹**이라(개수 모드표 →
개수 전역 캡 → 초수·금액) 하나를 풀어도 다른 겹이 다시 자른 실측 전례가 있다
("개수를 8개로 올렸는데도 초수 예산이 2개로 잘랐다" — config 주석).
**운영자가 등급으로 "여기 투자해"라고 해도 지금 구조에서는 상한이 말없이 이긴다.**

### ② 영상 품질·길이 손잡이가 전역 하나뿐이다

| 손잡이 | 현재 | 비고 |
|---|---|---|
| 영상 모델 | `VEO_MODEL` **전역 1개** (Lite $0.05/s) | 6곳에서 직접 참조 |
| 클립 길이 상한 | `VEO_CLIP_MAX_TIER_SEC` **전역 1개** (기본 4s) | `pick_clip_tier` |
| 이미지 모델 | `IMAGE_MODEL_BY_ROLE` — **역할별로 이미 있다** | 선례 존재 |

기전 도해 클립과 CTA 클립이 같은 모델·같은 길이다. "투자"라는 개념이 코드에 없다.

### ③ 예상 비용을 장면 단위로 볼 수 없다

`engine/cost.py` 에 `sequence` 참조 **0건**. cost_plan 은 편/컷 단위만 안다.
운영자가 "예상 비용을 보고 조절"하려면 **장면별로 얼마인지**부터 보여야 하는데
그 숫자가 어디에도 없다.

## 2. 핵심 설계 원칙

### P1 — 시퀀스 = 품질의 단위. 컷 = 시간의 단위. **구조 전환은 하지 않는다**

컷에는 나레이션·자막·TTS 실측 길이·clip_fit 이 붙어 있고 시퀀스에는 나레이션이 없다.
컷은 이미 `resolved_visual_plan.sequence_ref` 로 자기 시퀀스를 안다(v3 Phase 3 배선
완료) — 품질 판정이 그 참조를 타고 시퀀스 등급을 읽으면 된다. 새 구조가 필요 없다.

### P2 — 등급 키는 새로 만들지 않는다. `sequence_role` 이 이미 그것이다

```
MECHANISM_SEQUENCE   원리·구조·인과가 단계적으로 진행     → invest
RESULT_SEQUENCE      결과가 갱신된다                      → standard
REALITY_ANCHOR       실제 현장·제품 앵커                   → standard
FRAMING              훅·마무리·브릿지                      → economy
(시퀀스 밖 컷)        connective·CTA 등                    → economy
```

단 **돈·품질 판정의 입력은 라벨이 아니라 구조 판정이다** — `sequence_is_progression()`
을 통과한 시퀀스만 invest 가 된다(코덱스 리뷰 S4 의 판정을 그대로 소비). 등급을 위한
새 자기보고를 만들면 모델이 품질 예산을 속이는 문이 열린다(§5 R1).

### P3 — 조용한 강등 금지 (v1.1 에서 유일하게 "강제"되는 것)

상한이 등급 결정과 충돌하면 **말없이 깎지 않는다.** 선착순 강등은 제거하고, 남는
상한은 전부 **경고 + ⑤ 표시**로 바꾼다. 무엇을 깎을지는 운영자가 ⑤ 에서 숫자를 보고
정한다 — 자동 강등 사다리는 v2 로 미룬다(§7).

### P4 — 전부 영상은 등급제 **이후에** 켠다 (비용이 아니라 **정합성** 때문)

v1 에서는 비용 순서 논거였지만 v1.1 에서 더 중요한 것은 정합성이다: 전부 영상이 되면
I2V 연쇄의 유일한 경계(사이에 낀 스틸)가 사라져 **세계가 바뀌어도 사슬이 이어진다** —
엉뚱한 장소가 계속된다(§5 R2). 연쇄 경계를 `world_ref` 로 바꾸는 것(작업지시 Phase E)이
전부-영상의 선행조건이고, 이것은 비용을 나중에 생각하더라도 미룰 수 없다.

### P5 — 시퀀스 비용 관측: 이것이 v1.1 의 목적지다

`cost_plan.sequences[]` = `{sequence_id, role, tier, clips, video_sec, est_usd}`.
⑤ 확인 모달이 **장면별 표**로 보여 준다: 어느 장면에 얼마가 들어가는지, 등급이
무엇인지, 판정 불가로 economy 에 떨어진 컷이 몇 개인지(`tier_defaulted`).
원장(`generation_attempts.meta`)에도 `sequence_id`·`tier` 를 실어 **예상 vs 실제**를
나중에 대조할 수 있게 한다 — "예상 비용을 보고 조절한다"가 성립하려면 예상이
실제와 맞는지부터 검증돼야 한다(작업지시 Phase G ①).

## 3. 등급표 (안 — D1에서 확정)

| 등급 | 대상 | 영상 모델 | 클립 상한 |
|---|---|---|---|
| **invest** | MECHANISM_SEQUENCE (구조 판정 통과) | Lite (v1.1 은 전부 Lite) | **8s** |
| **standard** | RESULT_SEQUENCE · REALITY_ANCHOR | Lite | 4s |
| **economy** | FRAMING · 시퀀스 밖 컷 · 판정 불가 | Lite | 4s |

- v1.1 의 투자축은 모델이 아니라 **길이**다(8s vs 4s) — 긴 클립이 기전의 "변화가
  일어나는 것"을 보여줄 시간을 준다. 모델 상향(Fast)은 단가 미확정(⚠️ PRICING 주석
  "착수 시 공식 확정")이라 등급표 값만 바꾸면 켜지도록 자리만 만들어 둔다.
- 등급표는 config 상수다. **운영자가 예상 비용을 보고 이 표를 고치는 것**이
  v1.1 이 의도하는 조절 방식이다.

## 4. 예상 비용 관측치 (10컷 편 기준 — 참고용, 강제 아님)

| 시나리오 | 계산 | 영상비/편 |
|---|---|---|
| 현재 (영상 8개 × 4s Lite) | 8×4×0.05 | $1.60 |
| 전부 영상, 등급 없음 (10×4s) | 10×4×0.05 | $2.00 |
| 등급제 (기전 4컷 8s + 6컷 4s) | 4×8×0.05+6×4×0.05 | **$2.80** |
| 등급제 + 전부 영상 15컷 편 | 5×8×0.05+10×4×0.05 | $4.00 |

이 숫자는 ⑤ 화면이 보여줄 값의 미리보기다. 여기서 상한을 정하지 않는다 —
실렌더 후 실제 원장과 대조해서(Phase G) 운영자가 등급표·상한을 그때 정한다.
기존 안전망 중 잡 단위 `RENDER_BUDGET_CAP_USD` 는 **그대로 둔다**(폭주 방지 최후선).

## 5. 리스크 — 미리 인정하고 들어간다

- **R1 (자기보고 회귀):** 모델이 아무 시퀀스나 MECHANISM 이라 라벨하면 8s 를 얻는다.
  방어: invest 는 구조 판정 통과 시퀀스에만(P2). 구조 판정을 속이는 문제는 기존
  게이트(S1·S2) 관할.
- **R2 (전부 영상 × I2V 연쇄):** 경계를 `world_ref` 로 바꾸기 전에 전부-영상을 켜면
  세계가 바뀌어도 사슬이 이어진다. Phase E 가 선행조건이며 테스트로 강제한다.
- **R3 (상한 3겹의 잔존 충돌):** 상한을 경고로 바꿀 때 **한 겹이라도 강제로 남으면**
  등급 결정을 다시 말없이 이긴다(실측 전례). 세 겹 전부의 처리를 명시해야 한다
  (작업지시 Phase C 대상 목록).
- **R4 (관측 없는 폭주):** 예산 강제를 미뤘으므로 ⑤ 를 안 보고 발주하면 큰 편이
  그대로 나간다. 방어: ⑤ 모달에 편 총액을 **눈에 띄게**(기존 "총액을 보는 유일한
  지점" 관례 유지) + 잡 단위 캡 유지 + 예상-실제 대조(Phase G ①).
- **R5 (렌더 0회 상태):** "긴 클립이 기전 표현을 개선한다"는 아직 가설이다.
  Phase G ② 실측 전까지 invest 8s 의 근거는 채팅 실측(Veo I2V 애니메이트 확인)뿐이다.

## 7. v2 로 미룬 것 (비용 **강제**)

운영자 결정("비용은 나중에")에 따라 다음은 설계만 기록하고 구현하지 않는다:

- 편당 영상 예산 `PER_TOPIC_VIDEO_BUDGET_USD` 와 등급 순 배분기
- 강등 사다리(economy 부터 깎고 invest 는 마지막)
- `budget_exceeded` 표시 게이트(SB-2)

v2 착수 조건: Phase G 실측으로 **예상 비용이 실제와 맞는 것**이 확인된 뒤,
실제 편당 지출 데이터를 보고 운영자가 상한을 정할 때.

## 8. 하지 않는 것 (Non-goal)

- 컷 → 시퀀스 구조 전환(나레이션·자막·clip_fit·TTS 는 컷에 남는다 — P1)
- 새 파이프라인·새 렌더러·시퀀스 전용 DB 테이블(cost_plan JSONB 안)
- 이미지 등급 개편(`IMAGE_MODEL_BY_ROLE` 그대로)
- 만화식·설명판형 라인 변경 · 리포트 EQ 게이트(별도 작업)
- **비용 강제 일체**(§7 — v2)
