# 편차 기록 — 설명형 릴스 "사진클레이" 버전 (2026-11-10)

**운영자(2026-11-10):** "이건 일단 우리 엔진에는 새로운 버전으로 추가해서 넣자. 설명형 릴스-사진클레이 이런식으로 추가해줘."

같은 날 준마이·긴조·다이긴조 샘플(49초, 그림값 누적 $0.624)을 운영자와 여러 번 고쳐 가며 정한 것을 엔진에 옮겼다. 벤치마크는 `docs/벤치마크_햄스터_AI설명릴스_2026-11-10.md`.

## 무엇이 다른가

| | 영상 클립(기존, omni) | 사진클레이(새) |
|---|---|---|
| 장면 화면 | 장면마다 AI 영상 클립 | 장면마다 점토 그림 1장(정지) |
| 사는 것 | 시작 그림 + 클립(후보 2발 포함) | 그림만, 장당 약 $0.039 |
| 사람 선택 | 후보 클립 판정·선택 | 없음 — 완성 영상만 검수 |
| 목소리 | Edge, 장면별 | Edge Hyunsu **1.45배**, 장면 통째로 읽고 단어 시각에 맞춰 자막 |
| 길이 | 40~55초 | 30~70초 |
| 째리 | 없음 | 첫·끝 장면 그림 속, 나머지는 그림 모서리 스티커(코드가 그림) |

화면 틀: 째리 크림 바탕 고정 · 맨 위 제목(소재 제목) · 둥근 그림 카드 · 아래 자막(나레이션 전문, 뜻 단위로 끊음) · 오른쪽 아래 째리 로고 + "술째리고" · 왼쪽 아래 "생성형 AI 이미지 포함".

## 어디에 넣었나 — 가장 덜 건드리는 자리

설명형 편에는 원래 "제작 방식" 칸(`drink_explainer_episodes.provider`)이 있고 편을 만들 때 정하면 못 바꾼다. 여기에 `clay` 를 더했다. 초안·명세서·검수·게시 단계와 상태 기계는 그대로 쓰고, 세 작업만 갈라 탄다.

- **명세서(0원)** `drinks_explainer_queue._run_plan` → `build_clay_directive`: 대본 근거 검사는 클립과 **같은 함수**(`plan_problems`)다. 장면마다 TTS 로 길이를 재고 자막 줄·그림 지시·금액을 표로 만든다.
- **그림 구매** `_run_buy_clay`: 1번 그림은 째리 그림을, 2번부터는 "1번 그림 + 째리" 한 장을 참고로 그린다(공급자는 참고 그림을 한 장만 받는다). 돈은 기존 결재 원장(`drinks_paid.buy`)으로만 나가고, 같은 주문은 다시 사지 않는다. 다 사면 `assets_complete`.
- **조립(0원)** `_run_render_clay`: 산 그림을 저장소에서 꺼내기만 한다(시험이 사는 길이 없음을 확인한다). 자동 검사는 규격·소리·길이·moov 만 본다 — **정지 화면 검사는 하지 않는다**(원래 정지 그림이다). 품질은 사람이 본다.
- **DB(0079)**: provider 체크에 `clay` 추가 · clay 편은 **그림만 허용한 결재**로 산다 · clay 편은 선택 행 없이 `assets_complete` 에서 조립을 받는다. 클립 편 규칙은 그대로다.
- **스튜디오**: 릴스 초안을 승인할 때 "만드는 방식"(사진클레이 / 영상 클립)을 고른다. 기본은 사진클레이다. 명세서 표는 "화면 자막 · 그림 지시 · 째리(그림 속/모서리) · 금액".

## 예전 규칙과의 충돌 — 운영자 지시로 이 버전만 예외

0067 은 운영자 규칙 **"사진에 설명 하는건 안돼"** 로 설명형 소재에서 옛 그림 나열식을 막았다. 사진클레이는 정지 그림으로 설명하므로 이 규칙과 부딪힌다. 2026-11-10 운영자가 직접 샘플을 고쳐 가며 이 형식을 정하고 엔진에 넣으라고 지시했으므로, **사진클레이 한 버전에만** 푼다. 클립 경로와 옛 그림 나열식(local·paid) 막힘은 그대로다.

## 샘플에서 배운 것 → 코드 규칙

1. **그림 모델은 한자를 엉터리로 쓴다**(샘플 6장 중 5장, 벽 타일·라벨). 그림 안 글자는 전부 막고 라벨은 비운다. 샘플에서는 純米·吟醸 라벨을 코드로 덧썼지만, 위치가 장마다 달라 엔진에는 아직 넣지 않았다.
2. **실제 상표 라벨(닷사이·쿠보타)은 넣지 않는다** — 협찬처럼 보이고 주류 광고 규제가 걸린다. 운영자가 원했지만 이 이유로 대신 종류명 라벨을 제안했다.
3. **자막 줄마다 따로 읽히면 AI 같다** — 반쪽 문장도 끝나는 억양이 된다. 장면 통째로 읽힌다.
4. **Edge 는 앞뒤에 0.5~0.8초 빈 소리를 붙인다** — 첫 단어 직전~마지막 단어 직후만 쓴다(61초 → 48초가 된 이유 중 하나).
5. 모델이 그림을 아이콘처럼 작게 그리는 경우가 있어 여백을 잘라 크게 앉힌다.

- 주류 경고 문구는 영상에 없다(카드뉴스 출처 장에만 있다). 게시 캡션 규칙은 "AI 생성 영상" 한 줄이다.
