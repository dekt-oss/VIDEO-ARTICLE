# 밈형 제작 엔진 — 구현 기록 (2026-11-02)

총괄 계획 4단계의 0원 부분이다. 기획은 `docs/총괄계획_릴스3형식_수집부터게시까지_2026-11-02.md` §4-3·§5·§7(결정 4), `docs/기획_릴스3형식_트렌드보드_v2_2026-10-31.md` §5·§6-5·§7.
**이 기능은 아직 운영에서 돌지 않는다.** 코드와 파일만 있다. 0066 도 파일만 있다. 합격이라고 적힌 것은 전부 "돌아간다"이고, 재미·화면 품질은 운영자가 아직 안 봤다.

## 규칙을 어디서 지키나

- **박자 맞춤은 자동 게시되지 않는다.** 세 겹이다. ① 엔진 `publish_gate`·`assert_auto_publishable` ② 워커는 상태를 고르지 않고 DB(`drinks_meme_finish`)가 등급으로 정한다 ③ 표 제약 `drink_meme_sync_gate_ck` 가 손으로 넣어도 거부한다. 영상은 무음으로 만들고 "이 음원을 X초부터" 안내(`manual_audio_guide`)만 낸다. 앱에서 올린 뒤 운영자가 링크를 등록한다.
- **카드가 박자 맞춤이라고 적혀 있으면 박자 무관으로 승인되지 않는다**(`music_sync` 칸). 등급만 바꿔서 빠져나가지 못하게 했다.
- **안전 검사**: 음주 조장·미성년·과음 미화·음주운전·임신 중 음주 낱말(`config.DRINKS_MEME_UNSAFE_RULES` = SQL `drinks_meme_unsafe_rules`, 시험이 대조). 화면 글과 캡션 전부를 본다. ★ 낱말 규칙이라 돌려 말한 농담의 뜻은 못 본다. 그것은 승인 때 사람이 본다.
- **정보 밈은 근거 규칙을 탄다.** 승인된 근거 버전과 그 안의 주장 ID 가 없으면 승인되지 않는다. 표시를 안 해도 정보로 읽히는 말(단위 붙은 숫자·연구·효과 등)이 있으면 멈춘다. 숫자·양·권고는 `drinks_script_check.check_caption` 그대로이고, 근거가 나중에 취소되면 제작 직전에 멈춘다.
- **남의 영상·장면을 쓰지 않는다.** 엔진에 내려받는 코드가 없고(시험이 감시), 인스타·틱톡·유튜브 주소가 든 제작안은 저장 자체가 거부된다. 장면 칸은 `drink_media_assets` 의 우리 권리 파일만 받는다. 원본 글과 많이 겹치면 `meme_copied_text` 로 멈춘다.
- **돈:** 렌더 경로에 유료 호출이 없다. 리허설은 유료·네트워크 경로에 줄을 걸어 0회를 숫자로 남긴다. 반응 장면 구매(`buy_reaction_scene`, 약 $0.44)는 스위치가 꺼져 있고 공급자 연결이 없다. 글 초안 LLM 은 결재(`drink_develop_budgets`) 잔액에서 먼저 잡아야 부르고, 초안 1건 $0.02·3회가 상한이다. GitHub 워크플로에는 키가 없어 `--text` 는 거기서 못 돈다.

| 무엇 | 왜 못 봤나 | 틀리면 |
|---|---|---|

| 0066 을 운영 DB 에 적용 | 결재 대상. PGlite 로만 돌렸다 | 화면이 "0066 미적용"이라고 말한다 |
| 화면(`/drinks/memes` [밈 제작] 칸)을 실제로 열어 보기 | 0066·0063 이 운영에 없어 볼 대상이 없다. 타입 검사·린트·라벨 시험만 했다 | 적용 뒤 직접 본다 |

| 규칙 낱말의 누락·오탐 | 실제 카드가 없다. 첫 값이다 | 실제 카드로 고친다 |

## 켜려면 (운영자 결재 대상)

1. 0063·0064 다음에 `0066_drinks_meme_engine.sql` 운영 적용.
2. main 머지(그 전에는 워크플로가 없다). 비밀은 기존 `SUPABASE_URL`·`SUPABASE_SERVICE_KEY` 그대로다.
3. 카드에 [쓰자] → 칸 3개 입력 → [밈 제작]에서 제작안 쓰기 → 승인 → 게시 대기 확인.
4. 게시 연결·음원 게시 시험·반응 장면 구매는 각각 따로 결재.

## 되돌리기

- 화면 끄기: `web/app/drinks/memes/page.tsx` 의 `<MemeWorkSection …/>` 한 줄과 `loadMemeWork` 호출을 뺀다. `actions.ts` 의 `meme_*` 세 줄, `route.ts` 의 `drinks-meme.yml` 호출도 뺀다(가드 시험 한 줄 같이).
- 워커 끄기: `.github/workflows/drinks-meme.yml` 삭제. 승인된 제작안은 큐에 남고 돈은 나가지 않는다.
- 표 지우기: `0066` 머리말의 되돌리기 문장. 다른 형식의 표는 `drink_develop_holds` 칸 하나 말고 건드리지 않는다.
- 버킷의 `drinks/memes/` 파일은 따로 지운다. 초안으로 되돌리면 옛 파일은 기록 없이 버킷에 남는다(덮어쓰지 않으려고 작업마다 새 위치를 쓴다).
