## 4. 실행

```bash
# 로컬 (ffmpeg·폰트 필요. Windows 는 폰트 때문에 권장하지 않음)
python -m engine.render 85cc15a7-e7e8-4551-a6da-892306ef1e45

# GitHub Actions (정본)
# ① 대시보드 ⑤ 화면에서 이 지시서를 승인 → 큐 적재
# ② Actions → render → Run workflow → mode=poll
#    (GITHUB_DISPATCH_TOKEN 이 있으면 승인만으로 즉시 시작)
```

★ **큐를 먼저 확인한다.** `mode=poll` 은 큐를 통째로 소비하므로, 다른 잡이 쌓여 있으면
  한 번의 실행이 전부 돌아간다. 이 렌더만 돌리려면 큐에 이 건만 있어야 한다.

## 7. 이 렌더가 답하지 않는 것

- **"8초가 4초보다 나은가"** — 짝비교(G2)가 답한다. 이번 것은 8초 쪽 한 편이다.

- **"품질이 됐는가"** — G3(벤치마크 비교) 전에는 말하지 않는다(기획 §12-3).
  이번 렌더로는 **"등급제 배선이 화면까지 도달했다"**까지만 말할 수 있다.
