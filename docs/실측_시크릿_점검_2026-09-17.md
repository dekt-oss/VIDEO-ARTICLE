# 실측 — "미등록 시크릿 6개"의 정체 (2026-09-17)

> **한 줄:** 핸드오프가 남긴 "시크릿 6개 미등록"(남은일 2번)은 **막고 있는 것이 하나도 없었다.**
> 여섯 개 전부 폴백 경로가 있고, 그중 가장 의심스럽던 유튜브 성과 조회는 **실제로 돌려서
> 정상인 것을 확인**했다.

## 1. 지금 등록된 것 / 워크플로가 부르는 것

`gh secret list` 15개 · 워크플로가 참조하는 이름 22개(`GITHUB_TOKEN` 은 자동 제공).
차이가 6개이고, 핸드오프의 목록과 같다.

| 시크릿 | 쓰는 워크플로 | **없으면 어떻게 되나** |
|---|---|---|
| `ARIA_API_KEY` | report·report-draft·queues | **아무 일 없다.** 클라이언트가 `ARIA_MCP_URL → ARIA_BASE → fixture` 순으로 고른다(`engine/aria/client.py:8`). 프로덕션 경로인 `ARIA_MCP_URL` 은 **등록돼 있고**, 그 URL 에 토큰이 들어 있어 별도 키가 필요 없다(`config.py:2540`) |
| `ARIA_BASE` | 〃 | 〃 (REST 는 레거시·대안 경로다) |
| `REDDIT_CLIENT_ID` | engine | **동작한다.** `buzz.py:53` 이 자격증명이 없으면 공개 JSON(`www.reddit.com/r/…/new.json`)으로 폴백한다. 인증은 레이트리밋을 올려 줄 뿐이다 |
| `REDDIT_CLIENT_SECRET` | 〃 | 〃 |
| `YOUTUBE_ANALYTICS_CLIENT_ID` | analytics | **동작한다 — 실측함.** 업로드 클라이언트로 폴백한다(`providers/youtube.py:82`) |
| `YOUTUBE_ANALYTICS_CLIENT_SECRET` | 〃 | 〃 |

## 2. 마지막 하나를 눈이 아니라 **실행**으로 확인했다

폴백이 코드에 있다는 것과 실제로 도는 것은 다르다. 성과 조회 토큰(`YOUTUBE_ANALYTICS_
REFRESH_TOKEN_KO/EN`)이 **등록된 업로드 클라이언트로 갱신되는가**가 유일한 미지수였다.

업로드와 달리 이쪽은 읽기 전용이라 확인 비용이 0 이다. `scripts/check_youtube_tokens.py` 에
성과 조회 점검을 붙여 돌렸다.

```
[성과 조회]
  클라이언트: 업로드 클라이언트로 폴백(전용 값 미설정)
  ✅ 성과 조회 KO   토큰 유효 ✓ · 성과 조회 권한 ✓
  ✅ 성과 조회 EN   토큰 유효 ✓ · 성과 조회 권한 ✓
```

권한까지 본다 — **갱신 성공 ≠ 쓸 수 있음**이라는 것을 이미 한 번 비싸게 배웠다
(2026-09-14: 조회 전용 토큰을 업로드용으로 넣었는데 점검이 "3채널 정상"이라 했고 실제
업로드는 403 이었다). 그래서 `yt-analytics.readonly` 스코프가 실제로 붙어 있는지 확인한다.

업로드 3채널도 같이 정상이었다(하루지식하나 · a Paper a Day · 하루지식하나/리포트).

## 3. 결론 — 남은일 2번은 "할 일"이 아니라 "안 해도 되는 일"이었다

지금 넣어서 얻는 것:

| 시크릿 | 넣으면 얻는 것 | 급한가 |
|---|---|---|
| `REDDIT_*` | Reddit 레이트리밋 완화(버즈 가점 수집이 덜 끊긴다) | 아니다. 버즈는 **가점**이지 필수조건이 아니다(D2) |
| `ARIA_API_KEY`·`ARIA_BASE` | MCP 가 죽었을 때의 대안 경로 | 아니다. 지금 경로가 산다 |
| `YOUTUBE_ANALYTICS_*` | 성과 조회를 업로드와 **다른 OAuth 클라이언트**로 분리 | 아니다. 지금 클라이언트로 돈다 |

## 4. 남은일 3번(`OPERATOR_KEY` 교체)은 사장님 손이 필요하다

프로덕션 게이트는 **살아 있다**(실측: `https://video-article.vercel.app/` → `307 /unlock?next=%2F`).
교체는 "더 긴 무작위 값으로 바꾸는" 보안 강화이고, 새 값을 아는 사람이 `/unlock` 에 넣어야
하므로 사람이 한다. 값을 만들고 넣는 절차는 `README`·`CLAUDE.md` 의 환경변수 절 참조.

★ 순서를 지킬 것: **Vercel 환경변수를 바꾸고 재배포한 뒤** `/unlock` 에서 새 값을 넣는다.
  먼저 브라우저 쿠키를 지우면 그 사이 아무도 못 들어간다(고칠 수는 있지만 당황하게 된다).

## 5. 재발 방지

`tests/test_youtube_channels.py` 에 셋을 넣었다(변이로 잡히는지 확인함).

- 점검 스크립트가 보는 토큰 **이름**이 엔진이 읽는 이름과 같은가
- 점검 스크립트의 **클라이언트 폴백**이 엔진과 같은가 (한쪽만 폴백하면 점검이 거짓말을 한다)
- 점검이 `yt-analytics.readonly` 스코프를 **실제로** 확인하는가

`.github/workflows/youtube-token-check.yml` 이 성과 조회 시크릿도 넘기도록 고쳤다 —
Actions 에서 눌러도 같은 결과가 나온다.
