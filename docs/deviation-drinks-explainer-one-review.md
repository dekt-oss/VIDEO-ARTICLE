# 설명형 검수 한 번에 (2026-11-13)

운영자 지시: "검수하고 승인하는 버튼이 없다 — 흐름이 거슬리지 않게 쭉 이어지게."

## 원인
자동 검사를 통과한 설명형 영상은 사람 검수가 세 번 따로 있었다(과정 검수 → 품질 검수 6항목 → 최종 파일 승인).
앞의 둘은 '제작' 칸, 마지막은 '검수' 칸에 있었고, 결정 바는 '검수' 칸으로 보냈다. 그 칸은 품질 검수가 끝나기 전엔
버튼을 그리지 않아서 영상만 있고 버튼이 없었다.

## 바꾼 것
- DB 0085 `drinks_explainer_approve_all`: 세 함수를 차례로 그대로 불러 한 트랜잭션으로 기록한다. 하나라도 거부하면 전부 되돌린다.
- 화면: 영상 바로 아래 [검수하고 승인] 하나(볼 것 14가지는 접어 둔 목록). 불합격은 지금 단계로 되돌리는 기존 경로.
  결정 바 버튼도 같은 버튼을 누른다. 작업공간 밖의 옛 화면(hidePrimary=false)은 예전 3단계 그대로.
- ★ 체크박스 14개를 하나씩 누르던 것을 '목록을 보고 한 번 승인'으로 바꿨다. 기록에는 14항목 모두 확인으로 남는다 —
  운영자가 영상을 보고 누른 것이 그 확인이다.
