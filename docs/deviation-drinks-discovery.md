## 무엇을 만들었나

사실 근거와 **다른 표**에 "소재 발견 자료"를 둔다 — 사람들이 무엇을 궁금해하는지의 신호이지 근거가 아니다.

| 표 | 내용 |
|---|---|
| `drink_discovery_items` | 원문 URL·플랫폼·채널/커뮤니티·제목·확보한 요약(600자)·발견 시각·게시 시각(알 때만)·확보 범위·수집 상태(수집/수동)·권리 확인 상태·질문 문장(원문)·신호 |
| `drink_discovery_observations` | 공개 지표 관측(append-only). **제공된 지표만** — 미제공은 키가 없다(0 으로 채우지 않음) |
| `drink_discovery_candidates` | 규칙(discovery-v1)으로 묶은 후보 카드. 임시 점수·점수 이유·기준 버전 |
| `drink_candidate_items` | 자료 하나는 후보 하나에만(같은 자료로 여러 후보를 부풀리지 않음) |

화면 `/drinks/discover`: 채널 연결 상태 · 발견 수집원 · 후보 카드(열린/올림/기각/합쳐짐) · 아직 안 묶인 자료 · 수동 등록 · 발견 채널 등록.

## 후보 카드 — 규칙(LLM 0회)

- 신호: 질문·논쟁·오해·선택 고민·보관·신제품·행사(한·일·영 낱말 규칙). 질문 문장은 **원문 그대로**(번역·요약 안 함), 주소 조각·두세 단어 조각은 버린다.
- 묶기: 흔한 낱말·주종 이름을 뺀 낱말 Jaccard ≥ 0.34 + 겹친 낱말 2개 이상, 또는 같은 본문(전재). 판정이 아니라 제안 — 합치기·기각은 운영자.
- 관심 신호: **독립 출처 수**(같은 원출처 묶음·같은 본문 전재·같은 채널은 하나로) + 플랫폼별 지표 최댓값. **플랫폼끼리 더하지 않는다.**
- 카드: 핵심 질문(원문) / 독자 효용 / 발견 경로 / 관심 신호 / 첫 장면 제안("[규칙 제안]", 연출 장면 표기) / 영상·카드 적합성 / 추가 확인할 사실 / 중복 후보 소재.
- 임시 점수 discovery-v1 = 질문 신호 25 + 독립 출처(최대 4곳) 40 + 신호 종류(최대 3) 15 + 형식 적합 20. 이유 문장을 같이 저장한다. **승인·편성과 무관.**

## 후보 → 소재

운영자가 한국어 제목·질문을 **새로 쓴다**(남의 글을 옮기지 않고 술째리고의 질문·설명 각도로). 발견 자료는 URL만(metadata_only)
**질문·인기 신호(discovery)** 로 붙는다. A단계 규칙상 metadata_only·discovery 는 근거가 될 수 없다 — 근거로 쓰려 하면 저장이 거부된다(테스트).
근거는 공식·전문 원자료를 따로 등록해 발췌 대조·지지 검토를 탄다.
