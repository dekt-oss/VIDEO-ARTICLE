# 진단 — 주류 릴스 엔진 (2026-10-28)

주류 공장(술째리고)의 릴스 한 편이 **어떤 과정을 거쳐 어떤 품질로 나오는가**를 코드와 실측으로 적는다.
돈은 쓰지 않았다(무료 경로 1회 렌더 + 저장된 문서·코드만). 직접 돌려 본 것만 "됨"이고, 나머지는 "(미검증)".

## 0. 한 줄 판정

**흐름은 끝까지 돈다(제작안 → 영상 → 묶음 → 검수 → 릴스 발행 요청). 그러나 지금 나오는 릴스는 "글자 카드에 목소리를 입힌
것"이고, 파일 규격 세 가지(오디오 96 kHz · moov 위치 · 커버 PNG)가 인스타 릴스 문서와 어긋나 첫 실게시에서 거부될 수 있다.
무료 경로에는 대본 검사가 물려 있지 않아 원문 밖 숫자가 릴스까지 갈 수 있다.** 릴스는 실제로 한 번도 게시한 적이 없다(카드뉴스만 1회).

움직이는 장면(Veo)은 시험 스크립트(`scripts/drinks_pilot.py`)에만 있고 워커에는 연결돼 있지 않다 — 릴스는 언제나 **정지 그림 + 카메라 효과**다.

## 2. 무료 경로 실측 (오늘, 비용 0)

입력: `docs/drinks-pilot/whisky-water-v1.json`(위스키 v6.1, 장면 7 = 연출 4·도해 2·정리 카드 1, 나레이션 180음절).
실행: `render_video(job, tts="edge")` 로컬(Windows, ffmpeg 9.0.1, edge-tts 7.3.1, Python 3.14).

| 항목 | 실측 |
|---|---|
| 소요 | 77초 |
| 파일 | 1080×1920 · 30fps · H.264 High yuv420p 469 kbps · **AAC-LC 모노 64 kbps 96 kHz** · 30.5초 · 2.07 MB |
| 컷 길이(속도 전) | 2.99 / 5.63 / 6.21 / 5.63 / 5.10 / 5.63 / 5.39 초 = 36.6초 → 1.2× → 30.5초 |
| 말 속도 | 5.9음절/초(edge +10% 에 1.2× 가 겹친다. 속도 전은 4.9) |
| 자막 | 28줄, 뜻 단위 2~6어절, 최장 "한두 방울 넣어 맛을 살려요"(12자), 화면 62% 높이 가운데. 줄바꿈 없음(전부 한 줄) |
| 장면 전환 | 크로스페이드 0.5초 × 6, 컷 안 켄번스 + 펀치인 |
| 첫 3초 | 1번 카드(빨간 배지 "연출 장면 · 실제 제품·시설 촬영 아님", 회색 "대체 이미지(로컬 초안)", 큰 글자 "위스키 잔 하나, 스포이트에서 물 한 방울") 위에 자막 "위스키에 물을 / 왜 떨어뜨릴까요?". **그림 없음**, 아래 1/3 은 빈 갈색 |
| 음성 | 평균 −14.2 dB, 무음 장면 0 |
| 커버 | 1080×1920 **PNG**, 제목 + Q. 한 줄 |
| 경고 | qa warnings 0, 글자 잘림 0, 없는 글자 0 |
| 음원 | BGM 없음(`BGM_ENABLED=False`) — 저작권 문제 없음 |

프레임을 직접 봤다(0.3·1.5·2.8·4.5·9·14·19·24·29.5초 + 64칸 타일). 보이는 것은 7장의 갈색 글자 카드가 5초씩 바뀌는 것이고,
카드 글(explanation)과 자막(narration)이 **같은 내용을 두 번** 보여 준다. 릴스로서 눈길을 끌 요소는 없다 — 이 렌더는 문서에 적힌 대로
"흐름 검증용"이며 품질 검증이 아니다.

오디오 96 kHz 의 출처: 컷 파일·concat·자막 단계까지는 24 kHz 인데 **loudnorm 단계에서 96 kHz 로 바뀐다**(`engine/assemble.py:469`
`build_loudnorm_command` 에 `-ar` 이 없다 — loudnorm 필터가 내부 192 kHz 로 올리고 AAC 인코더가 96 kHz 로 떨어뜨린다). 논문·리포트
라인도 같은 함수를 쓰는데 유튜브는 받아 줘서 드러나지 않았다.

## 4. 유료 경로와 실사형 규칙이 물리는 지점

- `renderer=paid` 작업만: `drinks_script_check.check`(막힘이면 아무것도 안 삼) → `drinks_paid.build_image_items`(장면마다 `drinks_screen.engine_cut_for_image` 로 엔진 보정·도해 구조를 실음) → `buy`(재사용 목록 → `drinks_hold_spend` 상한 → Gemini → 확정·등록) → `render_video(images=…)` → `label_image`.
- 실사형 게이트(`drinks_screen.gate` = `photo_contract.evaluate`, 쇼츠에 안 맞는 길이 규칙 제외)는 **대본 검사 안에서만** 돈다. Jev 는 워커에서 항상 꺼져 있다(`jev=False`).
- GitHub Actions `drinks-produce.yml` 에는 GEMINI 키가 없다 → 유료 작업은 `api_key_missing` 으로 멈춘다. 유료는 **로컬 워커 전용**이다.
- 움직이는 장면(`clip_item`, Veo)은 시험 스크립트에만 연결. 결재 2단계(6초 영상 $0.30)는 보류 상태.
- 누적 지출 $0.921(사케 $0.212 + 위스키 $0.402 + v6.1 $0.307), 정가표 기준·청구서 대조 전.

## 5. 되는 것 / 안 되는 것 / 미검증

**되는 것(오늘 확인)**
- 제작안 → 무료 렌더 → 1080×1920 mp4 + 커버 → qa 가 한 번에 나온다(77초, 경고 0).
- 뜻 단위 자막, 장면별 무음 검사, 글자 잘림·없는 글자 검사, 장면 유형 배지.
- 관련 단위 테스트 51건 통과(`test_drinks_production/paid/script_check/publish_units/cards`).

**안 되는 것·약한 것**
- 릴스 파일 규격 3건 어긋남(96 kHz · moov 뒤 · 커버 PNG). 규격 자동 검사도 없다.
- 무료 경로에 대본 검사가 없다 — 원문 밖 숫자·양·권고가 있는 제작안도 렌더·검수·발행까지 간다(발행 직전 캡션만 검사).
- 영상은 글자 카드뿐이다. 제작안의 연출 정보가 영상 조립에 전혀 쓰이지 않고, 카드 글과 자막이 같은 말을 두 번 한다. 아래 1/3 이 빈다.
- 말 속도가 두 겹으로 빨라진다(TTS +10% × 1.2 = 약 1.32배, 5.9음절/초). 귀로 판정은 운영자 몫.
- 자막 앵커가 틱톡 기본이다(릴스 전용 0.68 미사용) — 해는 없지만 의도한 값이 아니다.
- 캡션 길이·해시태그 수 제한 검사 없음.

**미검증**
- 실제 릴스 게시(0회). 위 규격 어긋남이 실제로 거부되는지, 커버 PNG 가 받아들여지는지.
- GitHub Actions 에서 `drinks-produce` 영상 렌더(운영 한 바퀴는 카드 4장 로컬 렌더였다).
- 로컬 자막 글꼴: NanumGothic 요청인데 이 PC 에 없어 libass 가 대체 글꼴을 썼다(어느 글꼴인지 미확인). CI 는 fonts-nanum 설치.
- 실기기에서 상단·하단 UI 와의 겹침.
- 릴스 성과 지표 이름 `ig_reels_avg_watch_time`.
