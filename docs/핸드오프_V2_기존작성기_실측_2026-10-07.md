### 새 V2 흐름 (2026-10-07 운영자 "추천대로")
1. **생각 단계**(`engine/explanation_reasoning.py`) — 이 편의 질문·관심 이유·통념→반전·이야기 틀·설명 단계(질문/답/화면)·풀 용어·길이 45~120초.
2. **기존 작성기**(`scriptgen` / `report_scriptgen`) — 생각 단계 설계를 `instruction` 칸으로 받아 대본을 쓴다(`engine/v2_writer.py::design_instruction`). 후킹·4막·말투는 기존 규칙 그대로.
3. **V2 사실 검증관**(`semantic_fidelity.review_scenes`) — 장면마다 그 장면이 가리킨 근거(claim_ids·source_facts·리포트 reasoning_id → 근거 id)와 문장을 대조. 진짜 지적이면 지적을 붙여 **한 번** 다시 쓴다.
4. **지시서** — `v2_directive_bridge.generate_from_script` 가 기존 지시서 생성기에 그 대본을 평소 초안처럼 넘긴다.
- 스위치: `V2_WRITER=production`(기본) | `v2`(옛 V2 전용 작성기 — 후킹이 퇴화했던 경로).
- 실제 모델로는 **아직 한 번도 안 돌렸다(미검증)**. 가짜 모델 테스트만 있다(`tests/test_v2_writer.py`).

## 2. 왜 이렇게 바뀌었나 (운영자가 화난 이유 — 반복하지 말 것)

1. **기획안 대비 재검토**(`docs/전체재검토_ExplanationEngine_v2_2026-10-05.md`): 원래 V2 의 "생각하는 단계"가 비어 있었고(Fact Sheet 재분류), 대본이 기획안이 금지한 요약 나열이 됐다. 첫 리뷰에서 못 거른 것은 우리 잘못이다.
2. **V2 전용 작성기 대본은 일반 시청자 후킹이 퇴화했다.** 기존: "뇌세포의 단 1%만 건드렸는데, 한밤중처럼 깊은 잠에 빠질 수 있을까요?" / V2: "피질 안 극소수 장거리 억제 뉴런이 잠을 켤 수 있을까요?" — 그래서 말은 기존 작성기에 맡겼다.
3. **유료 실행 반복으로 약 $6.6 을 썼다**(이틀간 31회, 검사를 통과시키려고 고치고 세 편을 통째로 재실행). 운영자: "마음대로 검증에 돈 쓰지 마".

## 3. 다음 세션이 할 일 (순서대로)

1. **운영자에게 금액을 말하고 허락받는다** — 신피질 논문 한 편, 한 번, 예상 약 $0.3~0.4.
2. 허락되면 실행(대본 모델은 deepseek 로 대신 — Gemini 3.8 Flash 크레딧 없음):
   ```bash
   MODEL_V2_NARRATION=deepseek-v4-pro MODEL_SCRIPT=deepseek-v4-pro MODEL_V2_CRITIC=gemini-2.5-pro python -m scripts.compare_explanation_v2 paper 525cead5-a4e8-4bab-805a-bf4b8bd5d076 --directive-id 8cc86e35-a2d6-4481-be6b-e9a6d1d70eef --with-model
   ```
   - 기존 작성기는 `config.MODEL_SCRIPT` 를 쓴다(기본 gemini-3.8-flash, 크레딧 없음 → 402). 그래서 `MODEL_SCRIPT` 도 바꿔 준다.
     **이것은 운영 대본 모델과 다른 조건**이라는 것을 결과 보고에 적는다. 같은 조건으로 보려면 Gemini 충전 후 `MODEL_SCRIPT` 를 빼고 돌린다.
   - 결과: `artifacts/explanation-v2-phase11/paper-525cead5-…-model-<UTC>.md` — 위 "기존 Production 대본", 아래 "V2 대본(설계: 생각 단계 · 말: 기존 작성기 …)".
3. **결과를 운영자 기준으로 판정해서 보고한다** — 통과 여부가 아니라:
   - 첫 질문이 기존만큼(이상) 후킹되나?
   - 따라가다 보니 원리까지 이해되나(기획안 §23)?
   - 길이(45~120초 안, 억지로 늘리지 않았나)?
   - 기존 대본과 나란히 인용해서 보여 준다.
4. 막히면 **유료 재실행 금지** — 저장된 결과 JSON 을 오프라인으로 다시 검사해 원인을 찾고, 운영자에게 보고한 뒤 허락받아 그 한 편만 다시 돌린다.
5. 운영자가 좋다고 하면: 다른 두 편(조화 음파 `81bdabc6-7c59-4552-b7c4-3a552b91725c` / 디렉티브 `a5940cc7-48f1-4136-a1ba-e55da6eee817`, 위성 레이저 리포트 `d16ed484-44f5-43ec-878a-655abcd756d1`) → `--with-directive` 로 지시서 → 마음에 드는 편 `--save-directive` 저장 → 운영자가 대시보드에서 렌더. 각 단계 돈 들기 전 허락.

## 4. 비용 규칙 (운영자 지시 — 반드시)

- 돈 드는 실행 전에 **예상 금액을 말하고 허락**받는다. 허락 범위 밖으로 넓히지 않는다(한 편이면 한 편).
- 고친 것은 먼저 **저장된 결과로 오프라인 재검사**(비용 0). 다시 돌려야 하면 **실패한 그 한 편만**.
- 더 비싼 모델로 바꾸기 전, 같은 문제로 두 번째 유료 실행 전 → 누적액 말하고 묻기.
- 테스트는 실제 모델을 못 부른다(`tests/conftest.py` 가드). 새 단계에는 가짜 caller 를 넘긴다.
- 참고 단가(실측): deepseek-v4-pro 생각 단계 $0.03~0.06/회, Gemini 2.5 Pro 검증관 약 $0.15/회.
