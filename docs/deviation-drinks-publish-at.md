# 예약 게시 깨우기 + 막히기 전 한 번 더 찾기 (2026-11-18)

## 예약 게시 깨우기 (`.github/workflows/drinks-publish-at.yml`)
- **왜:** 발행 워커 크론(KST 07:00~23:30 매 30분)이 실제로는 하루 서너 번만 돌았다(11-17~18 실행 기록). DB 는 예약보다 2시간 넘게 늦은 게시를 하지 않으므로, 크론만 믿으면 예약이 통째로 빠질 수 있다.
- **어떻게:** [예약 게시](`publication_go`, 지금이 아님)를 누르면 웹 라우트가 이 워크플로를 `at=예약 시각`으로 부른다. 그 시각까지 기다렸다가 `drinks-publish.yml` 을 부른다. 잡 하나는 6시간까지라 남은 시간이 길면 5시간 40분 기다린 뒤 자기 자신을 다시 부른다.
- **게시 여부는 그대로 DB 가 정한다.** 이 워크플로는 깨우기만 한다. 비밀을 쓰지 않는다(GITHUB_TOKEN 의 workflow_dispatch 예외).
- 되돌리기: 워크플로 파일을 지우고 `web/app/api/drinks/route.ts` 의 `drinks-publish-at.yml` 분기를 지운다.

## 막히기 전 한 번 더 찾기 (`engine/drinks_develop.run_evidence` 의 `dig`)
- **운영자(2026-11-18):** "내가 원한 건 야마자키 주제 하나가 아니라, 내가 원하는 주제가 선택되면 그 주제를 가지고 어떻게든 내용을 만들어 줬으면 좋겠어."
