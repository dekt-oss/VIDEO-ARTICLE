## [1] 지시서가 승인을 통과한다 ← 지금 여기

**무엇을 하는 단계인가:** 논문·리포트를 넣으면 "어떤 화면을 어떤 순서로 만들지" 적은
지시서가 나오는데, 그게 검사(게이트)를 통과해야 렌더로 갈 수 있다.

**왜 아직 못 지나갔나:** 오늘 하루 실측 4회로 원인을 하나씩 걷어냈다.

| 막던 것 | 상태 |
|---|---|
| 주장이 원문에 있는지 대조 불가 | ✅ 해소 — 논문 원문 46,952자 확보 |
| 컷 수 부족 | ✅ 해소 — 등급제 8초 vs 게이트 5초 어긋남 수정 |
| 길이 초과(71초) | ✅ 해소 — 49초 |
| series_split(모든 논문을 막던 것) | ✅ 해소 — 명세대로 권고로 내림 |
| 게이트 오탐(`40 meters`·`회전축`) | ✅ 해소 |
| **세계 선언이 화면** | ❌ **여기서 막혀 있다** |

**남은 것 하나:** 시퀀스의 `world`(그 장면이 머무는 세계)를 모델이 `SOCIAL_MEDIA_FEED`,
`AD_CREATION_INTERFACE` 같은 **화면**으로 잡는다. 세계가 화면이면 그 안의 컷이 전부 UI
렌더가 된다 — 실사형이 성립하지 않는다.

처방을 넣었고(**화면을 세계로 잡지 말고, 그 화면을 보는 사람과 자리를 세계로**)
**아직 검증 안 됐다.** 다음 재생성 1회($0.08)로 확인한다.

**끝나는 조건:** `approval_blocked: false`.

## [2] G2 — 8초가 정말 나은가 (유료 실측)

**왜 필요한가:** 등급제의 핵심 가정이 "기전 컷에 8초를 주면 좋아진다"인데
**증명된 적이 없다.** 1편만 렌더해서는 말할 수 없다 — 비교 대상이 없기 때문이다.

**방법:** 같은 시작 이미지·같은 프롬프트·같은 모델로 **4초 vs 8초를 짝지어** 뽑아 비교.

**이 단계에서 같이 확인되는 것 (전부 자동 기록):** 등급제가 새로 넣은 경로가 처음 도는 자리다.
- invest 컷이 실제로 8초로 나갔나 (`VideoSpec.clip_sec` → provider 요청까지)
- 후보 2발 중 골랐나 (로그 `컷 N 후보 2개 → k번 채택`)
- 연출 계약 비트가 화면에 보이나
- **이미지·영상 비용이 원장에 남나** ← 이 경로는 아직 한 번도 검증 안 됨
- 정지 화면·출처 노출시간 (Q1·Q4)

**비용:** 약 $6 (2편). 소요는 **모름** — 등급제 이후 렌더가 없다. 상한 60분은 안전장치.

**끝나는 조건:** "8초가 낫다/차이 없다"의 **방향**이 나온다. 차이가 없으면 8초를 버리고
예산을 다른 데 쓴다.

## [3] G4 — 후보 2발이 정말 나은가 (유료 실측)

**왜 필요한가:** 지금 invest 컷마다 영상을 **2번 뽑아 좋은 쪽을 고른다.** 비용이 2배다.
그만한 값을 하는지 확인해야 한다.

**방법:** 1발 vs 2발-선택을 짝지어 비교.

**비용:** 약 $6

**끝나는 조건:** 기획 §11 이 정해 둔 판단 —
**후보 선택 효과가 길이 효과보다 크면, 다음 버전 예산은 길이가 아니라 후보 수에 쓴다.**

## [4] G3 — 벤치마크와 나란히 ★ 여기가 완성 판정

**왜 여기가 완성인가:** 기획 §12-3 이 못박았다 —
**"G3 통과 전에는 '돌아간다'고만 말하고 '품질이 됐다'고 말하지 않는다."**

**방법:** 벤치마크 영상과 나란히 놓고 정량 지표 5개 + 운영자 눈.
- Visual Change Rate(화면이 실제로 변하나)
- Static Hold Ratio(멈춰 있는 시간 비율)
- Camera Beat Density(카메라 연출 밀도)
- Repetition Rate(같은 장면 반복)
- Mechanism Progress Coverage(기전이 실제로 진행되나)

**비용:** 약 $3 + 운영자 판정 시간

**끝나는 조건:** 지표가 벤치마크에 근접 + **운영자가 보고 납득한다.**
지표는 인상평을 대체하는 것이지 **운영자 눈을 대체하지 않는다**(기획 §11 원칙).

## [5] 운영 누적 — 문턱을 실측으로 정한다

지금 **기록만 하고 아무것도 차단하지 않는 지표가 4개** 있다. 표본이 없어서 문턱을
못 정했기 때문이다. 렌더가 쌓이면 컷마다 자동으로 모인다.

| 지표 | 지금 | 필요 표본 |
|---|---|---|
| `world_drift` (세계를 떠났나) | 기록만 | 20개 이상 |
| `text_burn_in` (글자가 박혔나) | **방향이 반대** — 쓰면 안 됨 | 별도 검출기 필요 |
| `max_freeze_sec` (정지 화면) | 경고만 | 렌더 분포 |
| Q4 출처 노출시간 | 경고만 | 렌더 분포 |

`scripts/calibrate_clip_metrics.py` 는 **표본 20개 미만이면 문턱 정하기를 거부한다**(의도된 동작).
