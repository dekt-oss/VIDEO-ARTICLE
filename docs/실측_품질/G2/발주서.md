# 품질 실측 발주서 — G2: 길이 실측 — 4초 vs 8초

> **묻는 것:** 같은 장면·같은 프롬프트에서 **8초가 4초보다 실제로 나은가?**

★ 8초 쪽에만 연출 계약(비트)이 붙는다 — 그것이 invest 등급의 내용이다.

## 만드는 법

- 도구: **Veo(Gemini 웹)**, 비율 **9:16 세로**
- **시작 이미지는 두 팔이 같아야 한다.** 아래 `시작.png` 하나를 만들어 **양쪽에 같이** 쓴다.
- 각 팔의 프롬프트를 그대로 붙여넣고, 지정된 **길이**로 생성한다.
- 나온 파일을 `docs\실측_품질\G2\입력` 에 아래 이름으로 저장:

    - 4초 → **`A_4s.mp4`**
    - 8초 → **`B_8s.mp4`**

다 넣으신 뒤 알려주시면 **코드가 채점**합니다:

