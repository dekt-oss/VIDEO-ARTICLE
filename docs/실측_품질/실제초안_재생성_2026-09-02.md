# 실제 초안으로 photo 지시서 재생성 — 2026-09-02

`scripts/regen_from_draft.py`(PR #102)로 **Supabase 의 진짜 초안**(Moon Impactor,
`706e0791`, claims 10개, 원문 34,835자)을 써서 실사형 지시서를 만들었다.
오프라인 재구성본(`regen_directive_offline.py`)이 원문 부재로 판정 못 하던 축까지 돌았다.

**결과: 승인 차단이 3종 → 1종으로 줄었고, 남은 하나는 게이트가 옳게 잡은 것이다.**

## 1. 실측 경과 (유료 3회, 합계 약 $0.19)

| 회차 | 결과 | 얻은 것 |
|---|---|---|
| 1차 | **실패** — 출력이 16,384 토큰에서 잘림 | 토큰 상한 결함(§2-1)·원장 누락(§2-2) 발견 |
| 2차 | 15컷 생성, 차단 2종 | 초안 계승 결함 발견(§2-3) |
| 3차 | 15컷 생성, 차단 3종 | 게이트 오탐 2종 발견(§2-4·§2-5) |

3차 산출물 `docs/review-2026-08-31/moon_impactor_realdraft_v3.json` 을 **고친 코드로
다시 채점하면 photo·시퀀스 게이트가 둘 다 비고**, `series_split_required` 만 남는다
(추가 유료 호출 없이 검증 — 저장된 지시서를 게이트에 다시 태우면 된다).

## 2. 찾은 결함 5건

### 2-1. 지시서 출력 상한이 실제 크기를 못 담았다 (`config.LLM_DIRECTIVE_MAX_TOKENS`)

원문이 있는 실제 초안에서는 **Gemini flash 경로도** 16,384 에서 잘렸다(사고 토큰 0 —
순수 출력이다). 컷마다 `temporal_plan` 비트·`mechanism` 구조·`stage_mutations`·
`overlay_plan` 이 붙고 [컷 수] 규칙이 12컷 이상을 요구하니 출력이 4만 자를 넘는다.
→ **32,768 로 올렸다.** Fact Sheet 때처럼 "개수를 묶는" 답은 여기엔 안 맞는다 —
컷 수는 이미 목표 길이에서 역산돼 묶여 있고, 잘린 것은 개수가 아니라 컷당 계약의 두께다.

### 2-2. 잘린 호출이 비용 원장에서 빠졌다 (`llm._gemini_create`)

`_record_text_usage` 가 절단 예외 **뒤**에 있었다. 잘린 호출도 과금되는데(코드 주석이
스스로 "잘린 응답도 과금된다(실측)"이라 적어 놓았다) 원장엔 0원으로 남았다.
**출력이 상한까지 찬 호출** = 가장 비싼 호출일수록 기록에서 빠지는 구조였다.
실제로 1차 시도는 원장에 없다. → 기록을 raise **앞으로** 옮겼다.

### 2-3. ★ 초안의 시각 제안이 금지문을 이기고 계승됐다 (`directive.directive_user_prompt`)

2차 산출물의 화면 그래픽 위반 3건이 **전부 초안 `video_prompts[]` 에 그대로 있던 문장**이었다:

```
컷12 ← "a graphic overlay appears indicating a crater diameter of '~40m'"
컷 9 ← "a digital timer overlay next to it displays a consistent rotation period"
컷 7 ← "an infographic overlay of a light spectrum graph appears over it"
```

첫 줄은 **8/31 에 G2·G4 클립 4개를 전부 망친 바로 그 문장**이다(`결과.md` §3).
프롬프트가 금지문과 "흐름·근거를 최대한 계승 … 통째로 버리지 말 것"을 동시에 말하고
있었고, 모델은 **계승을 골랐다.**

→ 실사형에 한해 초안 장면의 **시각 제안 4필드**
(`image_prompt`·`image_prompt_ko`·`video_prompt`·`video_prompt_ko`)를 입력에서 뺀다.
나레이션·근거·역할·길이는 그대로 넘긴다 — 프롬프트가 스스로 "나레이션 초안"이라
부르는 그것이다. 초안의 시각 제안은 만화식 전제로 쓰인 것이라("한국 웹툰 스타일…")
실사형엔 어차피 맞지 않는다. **만화식·나열식은 종전대로 전부 넘긴다.**

> 금지 어휘를 더 쌓아도 이건 못 이긴다. 입력에서 빼는 것이 구조적 답이다.

### 2-4. 게이트가 길이 단위 `meters` 를 계기판으로 읽었다 (`photo_contract._FORBIDDEN_SCREEN`)

```
"a large, circular crater, approximately 40 meters in diameter"  → 차단
```

분화구의 **실제 크기**를 말한 것이고 화면에 계기판을 요구한 적이 없다. 목록에
`meters?` 가 맨몸으로 있었다. 크기·스케일 서술은 실사형이 **권장하는** 표현이라
(크기 대비·전후 비교) 막으면 옳게 한 컷을 벌한다.
→ **계기 의미일 때만** 잡는다(`power/light/pressure/… meter`, `meter showing/reading`).
원래 목표였던 "digital timer overlay … displays" 는 `timers?`·`displays\s+showing` 이
그대로 잡는다(테스트가 셋을 같이 박아 둔다).

### 2-5. 여는 stage 의 세계가 원장에서 증발했다 (`visual_sequence.compute_lineage`)

```
S1  before={}  after={MOON, FALCON9}  mutations=[FALCON9 APPEAR]
S2~S4  변한 로켓만 싣고 간다
S5  before={..., MOON}  → vseq_state_lineage_mismatch (오탐)
```

2026-08-30 에 "안 변하는 배경이 사라진다"를 고치면서 씨앗을 `state_before` 로 잡았는데,
**여는 stage 의 `state_before` 는 비는 것이 자연스럽다**(그 앞에 아무것도 없다).
그래서 `state_after` 로만 선언된 MOON 이 계산 상태에서 빠졌고, S5 가 달을 물려받았다고
옳게 적었는데 차단됐다. **8/30 에 고친 것과 같은 오탐이 여는 stage 에서 재발한 것이다.**
→ 여는 stage 는 `state_after` 로 **빈 자리만** 채운다(이미 있는 키는 안 덮는다 —
진행 판정은 여전히 mutations 가 한다).
**골든B 는 그대로 차단된다**(그 S1 의 `state_after` 에는 `MOON_SURFACE` 가 없어서
S6 의 "Cratered surface" 는 여전히 계보 위반이다). 회귀 테스트로 박아 뒀다.

## 3. 남은 차단 1종 — 결함이 아니다

`series_split_required`. 초안 단계의 `content_plan` 이 이미 그렇게 정해 놓았다:

```
selected_mode: series_split
mode_warnings: forced_series_split_multiple_main_claims,
               mode_overridden:standard->series_split, too_many_spoken_numbers
```

독립적인 주요 주장이 2개 이상이면 한 편으로 만들지 않는다는 계약(§6-4)이다.
claims 10개짜리 논문이라 규칙이 옳게 작동했다. **푸는 방법은 게이트가 아니라 초안이다** —
주제를 쪼개거나 `content_plan` 을 다시 세운다. 이 논문을 렌더 1편 시험용으로 쓰려면
주장 수가 적은 다른 초안을 고르는 편이 빠르다.

## 4. 아직 확인 못 한 것

- **차단 0인 지시서를 실제로 만들어 보지는 않았다.** §1 의 재채점은 저장된 3차 산출물을
  고친 코드로 다시 태운 것이다(무료). 고친 프롬프트(§2-3)가 **생성 단계에서** 위반을
  줄이는지는 다음 유료 재생성에서 확인한다.
- 렌더는 여전히 0회다.

## 5. 이 세션이 배운 것

- **실제 초안으로 돌리자 오프라인 재구성본이 못 보던 결함이 5건 나왔다.** 그중 3건
  (§2-1·2-3·2-5)은 원문·초안이 실제로 있어야만 재현된다.
- **"금지문을 더 쓴다"로 못 이기는 위반이 있다.** 같은 프롬프트 안에 계승 지시가 있으면
  모델은 계승을 고른다 — 입력에서 빼야 한다.
- **게이트 오탐 2건이 전부 "단어를 맨몸으로 넣은" 데서 나왔다**(`meters`, 그리고 8/30 의
  `state_before` 씨앗). 유한 목록은 의미를 못 담는다.
