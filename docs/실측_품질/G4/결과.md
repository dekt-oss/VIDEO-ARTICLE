# G4 실측 결과 (2026-08-31) — Gemini 웹, API 비용 0

묻는 것: **"같은 8초에서 두 번 뽑아 고르는 것이 한 번 뽑는 것보다 나은가?"**

## 0. 결론

**후보 선택은 값어치가 있다.** 같은 프롬프트·같은 시작 이미지로 두 번 뽑았는데
결과가 **눈에 띄게 달랐고**, 한쪽이 명백히 나빴다. 한 발만 뽑았다면 그 나쁜 쪽이
그대로 화면에 나갔을 확률이 절반이다.

## 1. 실험이 성립하는가 — 먼저 확인

| | 요청 | 실제 |
|---|---|---|
| 1번째 | 8초 | 10.01초 |
| 2번째 | 8초 | 10.01초 |

요청과 다르지만 **두 팔이 똑같이** 벗어났다. 공통 편차라 짝비교는 그대로 성립한다
(G2 와 다르다 — 거기서는 팔마다 다른 길이를 요청했는데 실제가 같아져 조작 변인이
무너졌다). 도구가 이 둘을 구분해 말하도록 고쳤다.

## 2. 코드 채점

| | 정지 | 장면 전환 | **세계이탈** | 점수 |
|---|---|---|---|---|
| 1번째 | 0.0% | 2 | 0.850 | **1.0000** |
| 2번째 | 0.0% | 1 | **0.951** | 0.8500 |

점수차 0.15 — 기준(0.05) 위. **차이 있음.** 채택은 1번째.

## 3. 눈으로 본 것 — 점수보다 차이가 크다

```
1번째  0.2s 로켓 하강 → 3.5s 로켓 측면 → 6.5s 착지·먼지 → 9.5s 분화구 단면(라벨 거의 없음)
2번째  0.2s 로켓 하강 → 3.5s 로켓 측면 → 6.5s 착지·먼지 → 9.5s 분화구 단면
                                                            **+ 가짜 글자 범벅**
```

2번째 마지막 화면에는 `AGENT ZERO`, `LOYAL DEPLOY`, 숫자표, 지시선이 잔뜩 박혔다.
**전부 지어낸 글자다** — 원문에 없고 우리가 요구하지도 않은 텍스트다.
1번째의 같은 장면은 라벨이 거의 없다.

> **이것이 후보 선택의 실익이다.** 같은 지시로 두 번 뽑았는데 하나는 쓸 만하고
> 하나는 글자 범벅이었다. 한 발이면 동전 던지기다.

## 4. ★★ 그런데 점수는 그 이유로 고른 것이 아니다

점수가 1번째를 고른 근거는 **장면 전환 2 vs 1** 이었다. 글자 범벅은 **점수에 안
들어간다** — 지금 지표(정지·장면전환)는 텍스트를 아예 못 본다.

**즉 옳은 답을 우연히 맞혔다.** 순서가 반대였다면 글자 범벅 쪽이 뽑혔을 수도 있다.

이 저장소의 자세로 보면 이건 통과가 아니다: **판정이 맞은 이유를 코드가 설명하지
못하면 다음번에도 맞는다는 보장이 없다.**

## 5. ★★★ 네 클립 전부 세계를 떠났다 (G2 포함, 계통적 결함)

이번에 `world_drift` 신호를 추가해 재 보니:

| 클립 | 세계이탈 |
|---|---|
| G2 계약 없음 | 0.802 |
| G2 연출 계약 | **1.000** |
| G4 1번째 | 0.850 |
| G4 2번째 | 0.951 |

**넷 다 달 표면 실사로 시작해 "받침대 위 분화구 다이어그램"으로 끝난다.**
I2V 는 시작 프레임의 세계를 이어가야 하는데 마지막 구간이 다른 장면이다.

원인은 프롬프트 꼬리(양쪽 공통, 원래 지시서에서 왔다):

```
…then a graphic overlay appears indicating a crater diameter, whip-pan up…
```

**우리가 "그래픽 오버레이를 띄워라"라고 시켰다.** 그리고 그 오버레이가 수치를
담으니 글자가 박히는 것은 필연이었다.

> ★ 주목: G2 에서 **연출 계약을 붙인 쪽이 세계이탈 1.000 으로 가장 나빴다.**
> 움직임 점수는 가장 높았는데 세계는 가장 많이 떠났다 — 두 지표가 반대 방향을
> 가리킨다. 지금 점수 하나로는 품질을 대표할 수 없다는 증거다.

## 7. 미검증

- 표본 1쌍이다. **방향만 읽고 크기는 말하지 않는다.**
- "후보 2발이 평균적으로 낫다"가 아니라 "이번 1쌍에서 눈에 띄게 달랐다"까지가 답이다.
- `world_drift` 는 **밝기 분포 차이**라는 대리 지표다. 장면이 바뀌지 않아도 조명만
  크게 변하면 높게 나올 수 있다 — 표본이 쌓이기 전에는 신호로만 읽는다.
