# 품질 실측 발주서 — G4: 후보 실측 — 1발 vs 2발 선택

> **묻는 것:** 같은 8초에서 **두 번 뽑아 고르는 것**이 한 번 뽑는 것보다 나은가?

★ 두 팔의 프롬프트가 **완전히 같다.** 생성이 확률적이라는 것을 재는 실험이라
  같아야 한다. 벤치마크의 '8초를 뽑아 좋은 3초만 쓴다'가 이 가정 위에 있다.

## 만드는 법

- 도구: **Veo(Gemini 웹)**, 비율 **9:16 세로**
- **시작 이미지는 두 팔이 같아야 한다.** 아래 `시작.png` 하나를 만들어 **양쪽에 같이** 쓴다.
- 각 팔의 프롬프트를 그대로 붙여넣고, 지정된 **길이**로 생성한다.
- 나온 파일을 `docs\실측_품질\G4\입력` 에 아래 이름으로 저장:

    - 1번째 → **`A_take1.mp4`**
    - 2번째(같은 프롬프트 재생성) → **`B_take2.mp4`**

다 넣으신 뒤 알려주시면 **코드가 채점**합니다:

```bash
python -m scripts.quality_experiment judge G4
```
