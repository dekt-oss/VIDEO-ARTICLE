# 수정안 v2 — 역할별 화면시간 (2026-09-09 개정)

외부 리뷰 판정 **GO WITH CHANGES** 를 반영해 전면 개정했다.
**R1~R3 를 차단 게이트로 넣지 않는다.**

> v1 은 커밋 `a66e6d0` 에 있다. 무엇을 왜 접었는지는 §6.

---

## 0. 리뷰가 뒤집은 것 — 코드로 대조 완료

리뷰의 코드 지적 넷을 main 에서 직접 확인했다. **전부 사실이다.**

| 지적 | 확인 |
|---|---|
| `evidence_role` 은 enum 검사만 하고 내용 정합은 안 본다 | `normalize_directive` 1836행 — 사실 |
| `feedback_prompt` 은 차단이 없으면 빈 문자열을 돌려준다 | 함수 앞부분 조기 반환 — 사실 |
| `generate()` 는 차단·등급미달이 없으면 재생성을 안 한다 | 2285행 `if not first_reasons and not first_short: return` — 사실 |
| 초안이 E2(대상·지역·기간)를 **모든 영상 필수**로 요구한다 | `scriptgen.py` 42·144행 — 사실 |

**그래서 v1 의 전제가 무너진다.** 자기보고 라벨에 차단을 걸면 모델은 내용을 그대로 두고
`scope` → `mechanism` 으로 **라벨만 바꿔** 통과할 수 있다. 세 지표가 동시에 좋아지는데
영상은 하나도 안 좋아진다. 이 저장소 원칙("모델의 자기보고를 믿지 않는다")과 정면 충돌이다.

**그리고 더 급한 결함이 이미 코드에 있었다.** `photo_subject_dominates` 는 정확한 처방
문장까지 갖고 있는데, 경고만 뜬 산출물에는 **그 처방이 모델에게 전달되지 않는다.**
재생성 조건이 차단뿐이기 때문이다. 이번 문제("생쥐가 화면의 51%")를 이미 감지하고 있었고
고칠 말도 갖고 있었는데 **말을 건네지 않고 있었다.**

## 1. Phase A — 지금 넣는 것 (차단 없음)

### A1. 초안 단계: scope 압축 ★ 원인에 가장 가깝다
`engine/scriptgen.py`. E2(대상·지역·기간)를 **한 씬으로 묶게** 한다.
계통·월령·표본·투여기간을 각각 독립 씬으로 쪼개지 않는다. 결론 해석이 달라지는 조건만
나레이션하고 나머지는 화면 카드로 넘긴다.

> 이번 편 컷5·6·7 이 정확히 그 팽창이다:
> "20개월령 암컷 C57BL/6 생쥐에게" / "3개월간 투여하여" / "수명 기간 동안 진행되었고요"
> → "20개월 된 생쥐에게 석 달간 투여했습니다" 한 문장이면 된다.

지시서 단계에서 사후 교정하는 것보다 여기가 원인이다.

### A2. 지표만 기록 (telemetry)
`evaluate()` 의 `stats` 에 셋을 넣는다. **경고도 차단도 아니다.**
- `reference_role_share` (scope+method+connective)
- `mechanism_share`
- `first_mechanism_start_share`

문턱은 새 표본을 보고 나중에 정한다. v1 의 30%/45% 는 **쓰지 않는다**(§6).

### A3. `photo_mechanism_starts_late` — 재생성 가능 경고
첫 `mechanism` 컷이 전체의 **40%** 를 넘겨 시작하면 경고.
조건: 소재가 기전을 지불할 때만(`mechanism_claim_count > 0`).

**40% 는 calibration 값이다 — 검증된 품질 문턱이 아니다.** v1 이 "추측값 없음"이라고
쓴 것은 과장이었다. 표본 5편(20·39·43·49·51%)에서 고른 값이고 사람 평가와 연결한 적이 없다.

### A4. 경고도 재생성을 띄운다 ★ 이번 세션에서 가장 값어치 있는 변경
`config.RETRYABLE_QUALITY_WARNINGS` 를 새로 두고, 그중 하나라도 있으면 **품질 교정
재생성 1회**를 허용한다. 승인 차단은 여전히 아니다.

초기 목록:
- `photo_subject_dominates` (연구 대상이 화면을 먹는다 — 이번 문제)
- `photo_narrative_no_mechanism` (대본이 원리를 말하지 않는다)
- `photo_hook_visual_repeated` (훅 두 컷이 같은 그림)
- `photo_mechanism_starts_late` (A3)
- `photo_role_claim_mismatch` (A5)

계약: **경고 → 재생성 1회 → 그래도 남으면 경고인 채로 사람에게 보여준다.**
오탐이 생산을 막지 않는다는 기존 철학을 지키면서, 경고가 장식으로 끝나는 문제를 없앤다.

### A5. `photo_role_claim_mismatch` — 명백한 라벨 세탁만 잡는다
완전한 의미 분류기를 만들지 않는다. **필요조건**만 본다.

| 역할 | 연결된 claim 이 만족해야 할 필요조건 |
|---|---|
| `mechanism` | `claim_kind` ∈ {mechanism, author_interpretation} |
| `magnitude` | `claim_kind`=number 이거나 `effect_size` 가 있음 |
| `scope` | `population` · `study_period` · `geography` 중 하나 |
| `method` | `study_design` · `treatment_or_exposure` · `comparison` 중 하나 |

**애매하면 재분류하지 않고 넘어간다.** 컷에 `claim_ids` 가 없거나 원장에서 못 찾으면
`unverifiable` 로 두고 아무것도 내지 않는다 — 판정 불가와 위반을 섞지 않는다.

목표는 역할을 코드가 맞히는 것이 아니라 **명백한 거짓 라벨을 통과시키지 않는 것**이다.
이것이 있어야 나중에 역할 기반 차단을 논할 수 있다.

### A6·A7. 넣지 않는 것
- **R2(mechanism ≥ 20% 차단) 삭제.** 코드에 이미 `need_mech = min(길이역산, 소재공급)`
  이라는 천장이 있고 근거도 적혀 있다("출처가 대는 것보다 많이 설명할 수 없다").
  논문이 기전 claim 을 1개 주는데 16초를 강제하면 반복하거나 지어낸다.
  claim 공급 기반 최소 컷 수가 환각 방지에는 더 나은 계약이다.
- **R4 신규 차단 코드 삭제.** v1 은 R4 를 철회한다고 써 놓고 구현 목록에는
  `photo_mechanism_cuts_missing` 을 남겨 **자기모순**이었다(리뷰 지적).
  정본은 기존 `photo_narrative_no_mechanism` 경고 하나다. 유사 코드를 더 만들지 않는다.

## 2. Phase B — 지시서만 재생성해서 확인 (영상비 0)

**영상을 바로 뽑지 않는다.** 지시서 재생성으로 아래를 먼저 본다.

- [ ] 컷5·6·7 의 scope 가 1개로 압축됐는가
- [ ] 첫 mechanism 이 앞으로 왔는가 (`first_mechanism_start_share`)
- [ ] `photo_subject_dominates` 수치가 내려갔는가 (직전 0.51)
- [ ] 계통·월령·투여기간이라는 **사실이 사라지지는 않았는가**
- [ ] `cut_detail_not_in_source` · `cut_relation_not_in_source` 가 새로 생기지 않았는가
- [ ] `photo_role_claim_mismatch` 가 뜨는가 (뜨면 라벨이 내용과 안 맞는다는 뜻)

좋아진 뒤에 전반부를 한 번 렌더한다(약 2달러).

## 3. Phase C — 문턱 승격은 표본을 보고

새 지시서 10~20편에서 역할-라벨 정합률 · 참고 비중 분포 · 첫 기전 위치 · 대상 비중 ·

그렇다면 40% 라는 지표 자체가 대리 지표로서 실패한 것이다.

## 4. 최종 목표는 역할 비중이 아니다

우리가 원하는 것은 "scope 비율이 낮다"가 아니라
**"같은 대상·같은 화면을 오래 보고 있지 않다"** 이다.

- **렌더 전:** `photo_subject_dominates` 를 개선한다. 지금은 `mouse/cage` 같은
  하드코딩 어휘로 찾는데, Fact Sheet 의 `population`·`treatment_or_exposure` 에서
  **이번 논문의 대상 어휘를 만들어** 찾는 쪽이 일반화된다.
- **렌더 후:** 인접 컷 지각 유사도 · 같은 대상의 연속 노출 시간 · 같은 구도 반복을
  실제 프레임에서 잰다. 역할 라벨보다 결과물에 훨씬 가깝다.

이건 Phase A 범위 밖이고, 방향으로만 적어 둔다.

## 5. 이번 편의 목표 상태

| | 흐름 |
|---|---|
| 지금 | 결과 → 숫자 → 계통/월령/기간 → 생쥐 → 생쥐 → (42초) 원리 |
| 목표 | 결과 → 숫자 → **연구 조건 한 번에** → **왜 그런가** → 이해시키는 화면 → 한계·의미 |

핵심은 생쥐 컷을 줄이는 것이 아니라 **배경용 대상 화면에서 설명하는 화면으로 시간을
옮기는 것**이다.

## 6. v1 에서 접은 것과 이유

| v1 | v2 | 이유 |
|---|---|---|
| R1 참고 역할 30%/45% 차단 | **지표만 기록** | `method` 를 참고로 뭉뚱그린 것이 과했다. 무작위 대조인지 관찰인지, 어떤 비교를 했는지는 해석에 필수일 수 있다. 그리고 목적에 더 가까운 `photo_subject_dominates` 가 이미 있다 |
| R2 기전 20% 하한 차단 | **삭제** | 소재 공급 천장과 충돌. 논문이 못 대는 만큼을 요구하면 반복·환각 |
| R3 첫 기전 40% 차단 | **재생성 경고** | 진단은 옳지만 40% 는 사람 평가와 연결 안 된 heuristic. 우회 가능성도 미검증 |
| R4 기전 컷 차단 승격 | **삭제** | 승격 조건 미달(19편 중 2편). 구현 목록에 남겨 둔 것은 자기모순이었다 |
| "추측값 없음" | **철회** | 실측 분포에서 고른 heuristic 이지 검증된 품질 문턱이 아니다 |
