### ★ 이 GO 가 무엇을 뜻하는지 정정한다 (2026-08-30, 코덱스 리뷰 §20)

이 문서의 GO 는 **`Production GO` 가 아니다.** 그렇게 읽히면 안 된다.

```
Architecture Feasibility : GO        ← 3-stage 참조조건 생성으로 세계·인물이 유지된다
Production Sequence Quality : UNVERIFIED
```

실측이 확인한 것은 딱 여기까지다: **3단계까지의 참조조건 생성에서 Visual Sequence
구조가 성립할 가능성이 있다.** 아래는 **아직 아무것도 재지 않았다** —

- 4 stage 이상에서의 identity 드리프트 (여기는 3단계까지만 쟀다)
- I2V 최종 프레임을 다음 stage 입력으로 넣었을 때의 연쇄 열화
- 카메라 규격을 문장에서 뺀 뒤에도 **의도한 구도가 유지되는지**
- 인물이 없는 세계(공장·데이터센터 — Equity 라인)에서의 연속성
- 실제 Phase 3 렌더 배선 · Equity 라인 전체

Phase 3 의 첫 검증도 전체 영상이 아니라 **3~4 stage 짜리 Mini Render 2편**이다
(작업계획서 §9-6). 그것이 통과해야 full render 로 간다.

## 1. 무엇을 했나

옥시토신 논문의 신뢰게임 세계 하나를 만들고, **이전 stage 화면을 참조로 넣어** 상태만
바꾸는 방식으로 3단계를 생성했다. 각 단계는 gemini-2.5-flash 멀티모달로 판정하고,
**사람이 콘택트시트로 다시 확인**했다.

```
S0  canonical frame (텍스트만)     두 남자·나무 테이블·금속 디스크
S1  TRANSFER     왼쪽 남자가 디스크를 밀어 보낸다
S2  ACCUMULATE   오른쪽에 디스크가 쌓인다
S3  TRANSFER     오른쪽 남자가 되돌려 보낸다
I2V S0 → 전환 클립 4초 (Veo, 720×1280)
```

원문 근거를 넘지 않았다(작업지시서 Paper §12) — 절차 상세·생리 경로는 그리지 않았고,
"두 사람이 테이블에서 토큰을 주고받는다"는 초록이 말하는 범위 안이다.

## 2. 연속성 결과 — v2 와 질적으로 다르다

4단계 내내 **같은 얼굴·같은 옷(회색 스웨터/네이비 셔츠)·같은 의자·같은 테이블 나뭇결·
같은 카메라 각도·같은 조명**이 유지됐다. 디스크만 움직인다.

v2 에서는 이것이 불가능했다. 컷마다 새 이미지를 만들었으므로 같은 인물을 다시 그리면
다른 사람이 나왔고, 그래서 "재사용(파일 복사)"밖에 선택지가 없었다 —
**연속성과 복붙이 같은 것이 되어 버린 구조적 원인이 여기 있었다.**

이제 셋이 갈라진다:

```
NEW_WORLD    새 세계를 만든다
CONTINUE     같은 세계에서 다음 상태를 만든다   ← 이번에 가능함이 확인됨
REUSE        같은 파일을 다시 쓴다              ← 변화가 없으면 금지(현행 게이트)
```

## 3. 설계를 바꾸는 발견 두 가지

### 3-1. ★ 정확한 개수는 지켜지지 않는다 — VSEQ-7 이 옳다

프롬프트는 `ten identical small metallic discs` 를 요구했는데 S0 는 **4개 묶음**으로 나왔다.
이후 stage 의 7/3, 9, 5/4 도 화면에서 성립하지 않는다. 확대(`probe_continuity_zoom.png`)에서
분명하다.

**따라서 정확한 수치를 물체 개수로 표현하는 경로는 설계에서 금지한다.**
정량값은 전부 CODE_VIZ/OVERLAY 로 간다(작업지시서 VSEQ-7 · Equity EQ-V4).
어제 v2 지시서의 컷7("동전 10개 vs 11~12개로 15% 표현")은 **애초에 성립 불가능한 계획**이었다.

시각이 표현할 수 있는 것은 **방향과 관계**다 — "늘어난다 / 옮겨간다 / 쌓인다".
"얼마나"는 화면 카드가 말한다.

### 3-2. ★ 멀티모달 판정을 정량 검증에 쓰면 안 된다

판정 모델은 S2 를 "**아홉 개** 코인 한 더미로 변했다", S1 을 "총 **일곱 개**"라고 답했다.
화면에는 그런 개수가 없다. **판정 모델이 의도를 따라 읽은 것이다**(질문에 의도한 변화를
같이 넣어 줬기 때문이기도 하다).

반면 identity·world·style·"변화가 보이는가" 판정은 **내 눈과 일치했다.**

→ 멀티모달 QA(D2)의 적용 범위를 좁힌다:

| 쓴다 | 쓰지 않는다 |
|---|---|
| 같은 인물·같은 세계인가 | 개수·수치가 맞는가 |
| 화면이 실제로 달라졌는가 | 값이 근거와 일치하는가 |
| 글자가 번인됐는가 | (그건 fact_ref/overlay 의 몫) |

그리고 판정 프롬프트에서 **의도한 변화를 미리 알려주지 않는** 형태를 Phase 3 에서 쓴다 —
알려주면 확인편향이 생긴다는 것이 이번에 관찰됐다.

### 3-3. ★ 영상에 카메라 규격이 글자로 박혔다 — World Lock 설계를 바꾼다

전환 클립을 프레임으로 열어 보니 화면 오른쪽 위에 **`35°` 가 크게 그려져 있다**
(`probe_continuity_video.png`). 출처는 명백하다 — 세계 프롬프트의
`35 degree isometric camera` 를 Veo 가 **화면에 쓸 라벨로 읽었다.**

이것은 오늘 아침 이미지에서 잡은 `MECHANISM` 글자 누출과 **같은 계열의 사고**다:
**우리가 기계에게 하는 말(규격·역할·설정)이 화면에 그려진다.** 그때는 역할 이름이었고
이번엔 카메라 각도다. 공통점은 둘 다 *"프롬프트 본문에 들어간 스펙 토큰"* 이라는 것이다.

그리고 현재 게이트는 이것을 못 잡는다. `photo_contract` 의 금지 어휘는
차트·라벨·숫자 요구를 보는데, `35 degree isometric camera` 는 **정당한 카메라 서술**이다.
어휘를 늘려서 막을 문제가 아니다.

→ **Phase 1 의 설계 요구사항으로 승격한다:**

1. **World Lock 과 Camera Grammar 는 자유 텍스트로 생성 모델에 전달하지 않는다.**
   `camera_base: 35deg_isometric` 같은 값은 **구조화 필드**로 두고, 렌더가 프롬프트로
   옮길 때 **각도·렌즈 같은 수치 규격을 문장에서 제거**한다(예: "35 degree isometric"
   → "elevated three-quarter view"). 리뷰 §6 의 World Lock 예시가 그대로
   `camera_base: 35_degree_isometric` 인데, **그 문자열을 그대로 보내면 안 된다.**
2. **번인 검사를 영상에도 적용한다.** 지금까지 종횡비·글자 검사는 이미지에만 있었다.
   I2V 결과 프레임도 같은 검사를 받아야 한다(Phase 3 멀티모달 QA 범위에 포함).
3. 그 밖에 관찰: 전환 클립에서 **인물이 거의 움직이지 않았고** 디스크 배치도 S0 와
   달라졌다 — Veo 가 시작 프레임을 애니메이트한 것이 아니라 **다시 그린 쪽에 가깝다.**
   I2V 를 "연속성 도구"로 쓰려면 이 성질을 더 재야 한다(§6).

## 5. 1차 실행에서 내가 틀렸던 것 (기록)

첫 판정은 **NO-GO** 가 나왔는데 계산 오류였다:

- Veo 클립비($0.20)를 **이미지 stage 비용에 섞어** 나눴다.
- 비교 기준을 `GEMINI_IMAGE_COST_USD`(flash 근사 $0.039)로 썼는데, 도해 컷은 **원래
  gemini-3-pro-image($0.134)를 쓴다.** flash 와 비교하면 "참조 조건 때문에 비싸졌다"가
  아니라 "원래 비싼 모델"을 벌하는 판정이 된다.

스크립트를 고쳤다(같은 모델 단가끼리 비교, 영상비 분리). **게이트가 틀린 기준으로 NO-GO 를
내면 옳은 방향이 폐기된다** — 오늘 아침 photo_contract 오탐 3건과 같은 계열의 실수다.

## 6. 미검증 / 다음에 재야 할 것

- **stage 4개 이상**에서 identity 가 유지되는지 — 이번엔 3단계까지만 쟀다. 드리프트가
  누적되는 지점이 어디인지 모른다.
- **I2V 체인**: 클립의 마지막 프레임을 다음 stage 입력으로 넣었을 때의 열화. 이번엔 전환
  1개만 만들고 체인을 잇지 않았다.
- **인물 없는 세계**(공장·데이터센터 — Equity 라인)에서의 연속성. 이번 실측은 인물 2명
  세계 하나뿐이다.
- **I2V 가 '시작 프레임을 애니메이트'하는지 '다시 그리는지'** — §3-3 에서 후자 쪽 징후를
  봤지만 표본이 클립 1개다. Phase 3 전에 몇 개 더 재야 한다.
- 카메라 규격을 문장에서 뺐을 때 **의도한 구도가 유지되는지** — §3-3 의 고침이 실제로
  통하는지는 아직 안 재 봤다.
