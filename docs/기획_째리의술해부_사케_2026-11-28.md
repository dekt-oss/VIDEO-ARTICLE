# 기획 — 째리의 술 해부 · 사케 「쌀로 빚었는데 왜 과일 향이?」 (2026-11-28 초안 v3)

형식: `docs/핸드오프_째리의술해부_엔진_2026-11-28.md`(2.5D 단면 + 카메라 + 토큰 + HUD). 정답 샘플(막걸리)과 같은 틀.
상태: **대본·기획 초안. 렌더·유료 호출 없음. 엔진 코드(M1~M3)는 아직 없다.**
경위: v1(도수) 폐기 → v2(손잡이 셋) → v3 소유자 지시 "대긴조 말고 다이긴조. 사실상 효모가 향을 다 내는 것 아니냐. 정미율과 온도가 각각 무엇에 가장 중요한지를 알려 달라".

## 1. 한 줄 기획
- **핵심 궁금증:** 쌀로 빚은 술에서 어떻게 사과·바나나 향이 날까?
- **답:** 향은 **효모가 발효하면서 만든다.** 쌀 깎기와 온도는 향을 만들지 않고, 효모가 **어떤 향을 얼마나** 내게 할지 정한다.
  - **정미율 → 겉층 기름(불포화지방산)을 없앤다.** 기름이 많으면 효모가 바나나 향을 덜 만든다.
  - **온도 → 덜 깎고 따뜻하게 익히면** 효모가 마커펜 같은 냄새(기조향)를 더 만든다. 긴조는 반대로 차갑게, 천천히.
  - **효모 고르기 → 사과 향을 많이 내게 개량한 효모**가 있다.
- **퀴즈:** 쌀 겉층에 기름이 많으면 줄어드는 향은? (1 바나나 · 2 사과 · 3 꽃 → 1)
