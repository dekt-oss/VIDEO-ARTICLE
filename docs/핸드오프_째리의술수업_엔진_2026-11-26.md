## 4. 시간 규칙 (내레이션이 시계)

- 문장 = 자막 한 장 = 음성 파일 하나. 자막 글자와 나레이션이 같다(`·` 는 말할 때 쉼표, 줄바꿈은 공백).
- 음성: Edge TTS `ko-KR-HyunsuMultilingualNeural`, rate **+10%**, 그다음 `ffmpeg atempo=1.055`(음 높이 유지, 소유자 '5% 빠르게').
  ★ `engine/motion` 의 리포트 라인은 1.2배속이다. 주류 형식은 **별도 설정값**으로 둔다(리포트 라인을 바꾸지 않는다).
- 앞뒤 무음을 잰다(silencedetect −40dB, 0.05초). `head = 첫 무음 끝 − 0.05`, `end = 마지막 무음 시작 + 0.08`.
  배치할 때 `data-media-start=head`, 길이 `end − head`.
- 문장 칸 = 말 길이 + **0.27초**(숨). 장면 첫 문장 시작 = 0.15초(첫 장면 0.2초).
- 장면 길이 = max(템플릿 최소 길이, 마지막 문장 끝 + 꼬리). 꼬리 기본 0.1, 집 규칙 1.3(검색 입력이 끝나고 칩을 읽을 시간), 마지막 장면 2.0(반복 재생 전 머묾).
- 템플릿 최소 길이(샘플 값): pour_infuse 4.6 · fill_and_notes 4.3 · scarcity_compare 3.8 · two_methods 4.4.
- 템플릿 안의 사건은 **문장 시작에 묶는다**(예: 도장 = 둘째 문장 시작 + 0.5초, 통 이동 = 둘째 문장 + 0.1초). 고정 초가 아니다.
- 정답 시각은 `timeline.json`. 엔진 결과와 장면 시작이 ±0.05초 안이어야 한다.

## 6. 편 지시서 (엔진 입력 계약)

정답 모양은 `episode.example.json`. 칸 이름은 그 파일을 따른다. 요약:

```jsonc
{
  "format": "jjeri_class", "version": 1,
  "series": "째리의 술 수업", "episode": "1교시", "topic": "버번 vs 셰리 캐스크",
  "voice": {"provider": "edge", "voice": "ko-KR-HyunsuMultilingualNeural", "rate": "+10%", "atempo": 1.055},
  "keywords": [{"word": "버번", "color": "#B45309"}, ...],       // 자막 색 — 주제마다 2개 + 술째리고
  "title_accents": {"버번": "#F0A93B", "셰리": "#F2836B"},        // 장 제목 색
  "chapters": [{"from_scene": "s1", "title": "버번 vs 셰리 캐스크"}, ...],
  "scenes": [{"id": "s3", "template": "truth_infuse_stamp", "tag": {"text": "실제로는", "tone": "tomato"},
              "source_chip": "Whisky Advocate", "slots": {...},
              "beats": [{"text": "그런데 갓 증류한 원액은\n사실 투명해요.", "claim_ids": []}, ...]}],
  "caption_draft": "..."
}
```

샘플의 `claim_ids` 는 비어 있다 — 손작업이라 근거 연결이 없다. **엔진이 만드는 편은 사실 문장마다 claim_ids 가 있어야 한다**(§7).
출처 칩 글자도 LLM 이 쓰지 않고, 가리킨 근거의 출처에서 코드가 만든다(리포트 motion 의 쪽수 규칙과 같은 원칙).

아이콘(SVG 함수, `tools/build.py` 의 `glass`·`barrel`·`vanilla`·`caramel`·`smoke`·`anise`·`grapes`·`plum`·`cherries`·`bottle`·`arrow`)을
**이름 목록으로 등록**하고 LLM 은 목록 안에서만 고른다. 새 주제에 필요한 아이콘(쌀·누룩·사케병·막걸리 사발 등)은 사람이 그려 등록한다 —
목록에 없는 아이콘을 요구하는 편은 렌더 전에 멈춘다(`icon_unknown`).

**편 구성 규칙(코드 검사로 막는다)**: 첫 장면 = 질문(`glass_pair_question` 류), 마지막 장면 = `vote_comment`, 그 앞 = `house_rule_search`,
요약 장면에 예외 칩 권장(warn), 장 제목 5~8개, 장면 8~14개, 전체 55~75초.

## 9. 함정

- **Edge 현수 rate 함정**: +15% 는 짧은 문장도 `NoAudioReceived`, +16% 는 문장에 따라 실패(2026-11-26 실측). +10% + atempo 로 간다. 실패 시 재시도 2회 뒤 잡 실패.
- **HyperFrames 버전**: 샘플은 0.9.19 로 만들었고 0.9.72 로 렌더 확인했다. 엔진은 `config.MOTION_HYPERFRAMES_PKG` 를 따른다.
- **자막 레이아웃 함정**: 자막 상자가 `display:flex` 면 핵심어 `<b>` 가 따로 줄을 차지해 글자가 흩어진다. 상자 안에 `<span>` 하나로 감싼다(샘플 그렇게 고침).
- **같은 요소를 여러 번 `fromTo`** 하면 HyperFrames 검사가 경고한다(`gsap_repeated_fromto_without_baseline`). 째리 뛰기처럼 반복은 `tl.set` 기준 한 번 + `tl.to(keyframes)`.
- **SVG 선 그리기**: `pathLength=1` + `stroke-dasharray="1 1.2"` + `dashoffset 1.1` 로 숨긴다(둥근 끝 점이 보이는 문제).
- **안전 영역**: 0.9.19 검사는 안전 영역을 안 봤다. 0.9.72 는 본다 — 반드시 `--safe-zone reels` 로 돌린다. `.stage` 95% 축소로 28px 글자가 27px 이 되어 `text_below_floor` 가 났다(라벨·댓글 표시는 30px 로 올림).
- **꼬리 짧으면 칩을 못 읽는다**: 검사의 `line_unread`(0.5초 + 낱말당 0.3초)를 지킨다.
- **마이그레이션 번호**: 0089 가 두 파일이다(`0089_drinks_evidence_research_fresh`, `0089_drinks_youtube_retention`). 새 번호는 원격 `schema_migrations` 와 대조해 정한다.
- **리포트 motion 을 바꾸지 않는다**: 1.2배속·레터박스 무대·자막 방식이 다르다. 공용 함수(TTS·무음 측정·정규화·렌더 호출)만 나눠 쓴다.
- 샘플의 출처 칩 내용(Whisky Advocate, Frontiers in Chemistry 2018)은 원본 릴스 캡션에서 옮긴 것이고 문장별 대조는 하지 않았다(미검증). 엔진 편은 근거 연결로 만든다.
