# REVIEW — 째리의 술 해부 · 막걸리 v2 · 2.5D 단면 (2026-11-28)

## 만든 결정
- 대본을 그림부터 짰다: 문장 10개 = 세계 4개(항아리 → 체 → 잔 → 퀴즈). 장면을 끊지 않고 세계 안에서 카메라가 밀고·빠지고·옆으로 간다.
- 흡수한 기법: 투시 항아리, 빨리 감기 HUD(▶ 실제 시간 → ⏩ ×10 → ×1,000 → ×20,000 → ⏸ 다 익음)+발효 계기, 카메라 다이브 중 토큰 변신(전분→단맛→술+탄산) 범례, 의성어(보글보글·싹싹·톡톡), 따라붙는 이름표, 갈림길 비교(청주 vs 막걸리), 도수 계기판, 숫자 퀴즈, 첫 장면과 같은 끝(반복 재생).
- 그림 칸은 창문(clip y 424~1036) — 확대해도 제목·말풍선을 덮지 않는다.

## 사실 확인
- 원본 대본에 없던 문장: "누룩이 쌀의 전분을 단맛으로, 그 단맛이 술과 탄산이 돼요"(발효 일반 원리, 출처 대조 안 함). 원본의 열량·단백질 문장은 뺐다.
- 도수 6~8도 흔함·3~12도는 원본 대본 그대로.

## 잰 것
- check --safe-zone reels: 오류 0. 경고 3개는 일부러 둠 — 빨리 감기 단계 표시 2개(0.35초씩 넘김이 연출), 명암 1개(의성어 글자, 테두리로 읽힘).

## 약한 곳
- 국자·청주 잔이 작다. 체 위 손은 단순한 그림. 잔 장면은 1교시 수준(평면)에 머문다.

## v2 (2.5D 단면) — 소유자 "그림 밀도 올려서 2.5D 단면 수준으로"
- 그림 부품을 tools/art25.py 로 모음: 빛은 왼쪽 위, 윗면 타원 세로 = 가로 × 0.17, 회전체는 profile(y) 하나로 모양 공유.
- 항아리: 닫힌 옹기(유약 원통 음영·띠·물결 무늬·하이라이트) → 앞 절반이 떨어져 단면(안쪽 벽·잘린 벽 두께·바닥 타원·뒤쪽 입술). 층은 앞면 + 표면 타원.
- 도구: 나무 받침(두께), 대나무 체(테 두께·원근 격자), 흰 사발(굽·입술), 나무 국자, 굽 있는 청주 잔, 두꺼운 유리잔(표면 거품·바닥 두께·반사), 계기판 받침.
- 토큰: 쌀알(그림자·광택), 단맛 보석, 술 방울(광택), 기포(하이라이트), 누룩 원판(옆면·곰팡이 점).
- 1판 빌더는 tools/build_v1.py 로 남김.
- 약한 곳: 손은 여전히 단순, 체의 테가 겹친 원판처럼 보일 때가 있음.
